# Шаблоны кейсов для блока «Отзывы и результаты»

Заполняйте короткими наблюдаемыми фактами. Одна карточка — одна история.

## Формула

1. **Кто:** имя/инициалы родителя · возраст ребёнка · класс или тариф  
2. **До:** какая была трудность (1 строка)  
3. **Результат:** что изменилось дома (1 строка)  
4. **Цитата:** живые слова родителя (1–2 предложения)

## Шаблон для сбора (скопировать родителю)

```
Имя родителя:
Возраст ребёнка / класс:
Тариф (разовое / индивидуальное / с преподавателем):

Что было трудно до занятий?
(например: не дочитывал, не мог пересказать, читал только по просьбе)

Что заметили через 2–4 урока?
(например: сам просит сказку, замечает чувства героя, легче пересказывает)

Любимый элемент платформы:
(сундук / Словики / видео / вопросы / творческий лист)

Цитата одним–двумя предложениями:
«…»
```

## Шаблон карточки на сайт

```html
<article class="proof-review proof-review--card">

  <p class="proof-review__result">Результат: …</p>
  <p class="proof-review__text">«…»</p>

```

## Примеры формулировок «До → Результат»

| До | Результат |
|----|-----------|
| Читал только по просьбе взрослых | Сам выбирает следующую сказку |
| Пересказ сводился к «не знаю» | Рассказывает, чего хотел герой |
| Быстро прочитывал, смысл ускользал | Замечает чувства и выбор героя |
| Трудно досидеть 20 минут | Доходит до сундука и ждёт награду |
| Родителю непонятно, что уже пройдено | Прогресс виден в кабинете |

## Чего избегать

- Общих фраз без возраста и «до»  
- Обещаний вроде «разлюбил гаджеты навсегда»  
- Сравнения детей друг с другом
