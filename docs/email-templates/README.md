# Шаблоны писем родителям

Файлы для ручной рассылки и персонализации текстов.

## Приветственное письмо

| Файл | Назначение |
|------|------------|
| `welcome-parent.html` | HTML-шаблон с плейсхолдерами `{{...}}` |
| `welcome-parent.txt` | Текстовая версия (для почтовых клиентов без HTML) |
| `welcome-parent-example.html` | Заполненный пример — откройте в браузере для превью |

### Тема письма

```
Добро пожаловать в Читательство
```

Или персонально: `Маша в Читательстве — ваша ссылка на уроки`

### Плейсхолдеры

| Плейсхолдер | Что подставить | Пример |
|-------------|----------------|--------|
| `{{SUBJECT}}` | Тема (только в .txt) | Добро пожаловать в Читательство |
| `{{PARENT_NAME}}` | Имя родителя | Анна |
| `{{CHILD_NAME}}` | Имя ребёнка | Маша |
| `{{MODULE_TITLE}}` | Название модуля | Сказки и смысл |
| `{{PROGRESS_URL}}` | Ссылка из админки / регистрации | `https://api.chitatelstvo.ru/progress/…` |
| `{{LINK_TELEGRAM_PAGE}}` | Страница привязки Telegram | `…/link-telegram/…/page` |
| `{{INTRO_PARAGRAPH}}` | Стандартное приветствие | Ребёнок … записан в школу… |
| `{{PERSONAL_PARAGRAPH}}` | **Ваш текст под каждого родителя** | Спасибо, что написали про… |
| `{{STEP_1}}` … `{{STEP_3}}` | Шаги «Как начать» | См. пример в `welcome-parent-example.html` |
| `{{TELEGRAM_HINT}}` | Пояснение про Telegram | Если выбрали Telegram — … |
| `{{CLOSING_PARAGRAPH}}` | Финальный абзац | Читайте в удобное время… |

### Готовые фразы для копирования

**INTRO (новый ученик):**
> Ребёнок {{CHILD_NAME}} записан в литературную школу Читательство. Мы рады, что вы с нами — здесь чтение становится живым приключением.

**INTRO (возвращающийся):**
> {{CHILD_NAME}} продолжает занятия в Читательстве — прогресс сохранён, можно идти дальше с того места, где остановились.

**STEP_1:**
> Откройте сказку на странице прогресса — кнопка «Начать урок» ведёт в интерактивный плеер.

**STEP_2:**
> Ребёнок смотрит видео и отвечает на вопросы в том же окне — баллы начисляются автоматически, без форм для родителя.

**STEP_3:**
> Загляните в «Словики» и трофеи — там видно, что уже получилось и что откроется дальше.

**CLOSING:**
> Читайте в удобное время, без спешки. Мы рядом, если понадобится помощь с первым уроком.

### Как отправить

1. Скопируйте `welcome-parent.html` в новый файл или редактор письма.
2. Замените все `{{ПЛЕЙСХОЛДЕРЫ}}` (поиск по `{{`).
3. Удалите блоки, которые не нужны: «Модуль», «Telegram», «Личное слово».
4. Отправьте с `lessons@chitatelstvo.ru` — вставьте HTML через «Исходный код» / «Rich HTML» в почтовом клиенте.
5. При необходимости приложите `welcome-parent.txt` как запасной plain-text.

### Автоматическое письмо при регистрации

Текст без оформления генерируется в `notifications/email_templates.py` → `build_welcome_message()`.  
HTML-шаблон выше — для **ручной** персональной рассылки из админки или личной почты.

### Превью

Откройте в браузере:

```
docs/email-templates/welcome-parent-example.html
```
