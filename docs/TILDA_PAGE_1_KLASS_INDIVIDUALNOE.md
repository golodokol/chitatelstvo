### Поля формы — настройка в Tilda

В каждом поле: **Content** → **Settings** → **Variable name** (имя для webhook).

| № | Тип поля в Tilda | Подпись (Title) | Variable name | Обязательное | Примечание |
|---|------------------|-----------------|---------------|--------------|------------|
| 1 | Input (text) | Ваше имя | `parent_name` | да | |
| 2 | Email | Email для новостей | `parent_email` | да | |
| 3 | Input (text) | Telegram (необязательно) | `parent_telegram` | нет | подсказка: «@username» |
| 4 | Input (text) | Имя ребёнка | `child_name` | да | |
| 5 | Input (number) | Возраст ребёнка | `child_age` | нет | подсказка: «7 или 8» |
| 6 | Select | Как присылать новости | `notification_channel` | да | см. опции ниже |
| 7 | **Hidden** | — | `module_id` | да | value = **`2`** |

**Select «Как присылать новости»** — в настройках каждой опции поле **Value**:

| Подпись option | Value |
|----------------|-------|
| На email | `email` |
| В Telegram | `telegram` |
| Email и Telegram | `both` |
| Только личная страница (без писем) | `web` |

**Скрытое поле `module_id`:**

- Тип: **Hidden field**
- Variable name: `module_id`
- Value: `2`
- Не показывать пользователю

> Если Hidden field недоступен в вашем тарифе Tilda — добавьте Zero Block:
> `<input type="hidden" name="module_id" value="2">`

### Webhook формы

**Form** → **Settings** → **Webhook** (или «Send data to URL»):

| Параметр | Значение |
|----------|----------|
| URL | `https://api.chitatelstvo.ru/webhook/register` |
| Method | POST |
| **Custom header** | Name: `X-Webhook-Secret` · Value: *(ваш секрет из `.env` на сервере)* |

**Success page:** выберите страницу «Спасибо» (блок 8) или создайте отдельную страницу и укажите её URL.

**Send to email (Tilda):** можно оставить копию себе на почту — это не мешает webhook.

3. `module_id=2` и webhook должны уходить **вместе с формой** (проверьте тестовой заявкой в CRM Tilda, что в данных есть `module_id: 2`).

## Шаг 10. Тест перед публикацией

1. Отправьте форму с тестовым email.
2. В **Tilda CRM** / логе webhook проверьте поля:
   - `module_id` = `2`
   - `parent_email`, `child_name`, `notification_channel`
3. На почту должно прийти письмо со ссылкой `https://api.chitatelstvo.ru/progress/...`
4. На странице прогресса:
   - **Модуль:** «Индивидуальное обучение, 1 класс»
   - **8 уроков** (пока «скоро», если не активированы на сервере)
5. Старый пилот без `module_id` по-прежнему показывает только «Колобок» — не путайте формы.

**Тест через curl** (с вашего компьютера, подставьте секрет):

```powershell
curl -X POST "https://api.chitatelstvo.ru/webhook/register" `
  -H "Content-Type: application/json" `
  -H "X-Webhook-Secret: ВАШ_СЕКРЕТ" `
  -d "{\"parent_name\":\"Тест\",\"parent_email\":\"test@example.com\",\"child_name\":\"Маша\",\"child_age\":7,\"notification_channel\":\"email\",\"module_id\":2}"
```

В ответе: `"module_id": 2`, `"module_title": "Индивидуальное обучение, 1 класс"`, `"progress_url": "..."`.
