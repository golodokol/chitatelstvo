# Пошаговая сборка страницы `/zapis` в Tilda Business

Делайте по порядку. Отмечайте галочкой каждый шаг.  
Код для Zero Block: **`docs/tilda_zero_zapis.html`** (открыть в блокноте, Ctrl+A → Ctrl+C).

---

## Этап A. Подготовка сайта (10 мин, один раз)

### Шаг A1. Войти в Tilda
1. Откройте [tilda.cc](https://tilda.cc) → войдите в аккаунт.
2. Откройте проект **Читательство** (где `chitatelstvo.ru`).

### Шаг A2. Цвета и шрифты (по логотипу)

См. **`docs/TILDA_BRAND.md`**. Кратко:

1. **Настройки сайта** → **Шрифты и цвета**
2. Заголовки и текст: **Nunito** (подключить из библиотеки Tilda)
3. Акцент / ссылки: `#5B7FA6`
4. Фон сайта по умолчанию: `#F9EFE1` (крем) или `#FFFFFF`

### Шаг A3. CSS кнопок

1. **Настройки сайта** → **Ещё** → **CSS для всего сайта**
2. Скопируйте блок CSS из `TILDA_BRAND.md`

### Шаг B1. Создать страницу

2. Назовите: `Спасибо за запись`.

### Шаг B2. URL

### Шаг B3. Контент
1. **+ Добавить блок** → **Обложка** → простой текстовый cover (CR01N).


5. Кнопка: `На главную` → ссылка `https://chitatelstvo.ru`

### Шаг C6. Блок 4 — Zero Block

**Самый важный шаг.**

1. **+ Блок** → в поиске введите **Zero** → **Zero Block (T123)**.
2. Клик по блоку → **Редактировать Zero Block** (кнопка «Edit» / карандаш).
3. В редакторе Zero:
   - **Settings** (шестерёнка): Container width **960px** или **1200px**, padding top/bottom **60px**.
   - Фон Zero: `#FAF6F0`.
4. Добавьте элемент **HTML** (иконка `</>` или Insert → HTML):
   - Откройте на компьютере файл `docs/tilda_zero_zapis.html`
   - **Ctrl+A** → **Ctrl+C**
   - Вставьте в HTML-элемент Zero Block
5. **Сохранить** Zero Block → **Закрыть** редактор Zero.
6. Клик по блоку на странице → **Настройки блока** → **Аncor (якорь)**:
   - Введите: `program`
   - (Тогда кнопка «Подобрать программу» с `#program` прокрутит сюда)
7. **Предпросмотр** страницы: проверьте — pills класса, 3 карточки, при клике «Разовое» появляется блок сказок.

### Шаг C7. Блок 5 — Корзина ST100 + оплата Т‑Банк

**Полная инструкция:** `docs/TILDA_PAYMENT_TBANK.md`

На Tilda эквайринг **Т‑Банка** работает только с блоком **ST100** (Магазин), не с формой BF503.

1. **+ Блок** → **Магазин** → **ST100** «Корзина с формой заказа» — **сразу под Zero Block**.
2. В **каталоге Tilda** создайте 3 товара-услуги: **1 490 / 1 990 / 4 990 ₽** (см. `TILDA_PAYMENT_TBANK.md`).
3. В **ST100 → Контент** добавьте поля (те же Variable name, что в webhook):

| Title | Variable name | Тип |
|-------|---------------|-----|
| Имя родителя | `parent_name` | text |
| Email | `parent_email` | email |
| Telegram | `parent_telegram` | text |
| Имя ребёнка | `child_name` | text |
| Возраст | `child_age` | number |
| Как присылать новости | `notification_channel` | select |
| *(скрыто)* | `module_id` | hidden |
| *(скрыто)* | `chosen_stage` | hidden |
| *(скрыто)* | `chosen_tale_number` | hidden |

4. **ST100 → Настройки:** «Открывать корзину после выбора товара» — **вкл**.
5. Кнопка в корзине: **Оплатить**.
6. **Webhook** на ST100 → `https://api.chitatelstvo.ru/webhook/register` + заголовок `X-Webhook-Secret`.
7. Включите **«Отправлять только после оплаты»** (если доступно).

**Zero Block:** кнопка «Оплатить» открывает корзину через `#order:Название =цена` (логика в `tilda_zero_zapis.html`).

**Отдельную форму BF503 с оплатой не добавляйте.**

### ~~Шаг C7. Блок 5 — Форма~~ (устарело — см. ST100 выше)

<details>
<summary>Архив: форма BF503 без Т‑Банка</summary>

1. **+ Блок** → **Форма** → **BF503**
2. Расположите **сразу под** Zero Block (перетащите блок стрелками вверх/вниз).
3. **Контент формы** → заголовок: `Контактные данные`
4. Подзаголовок: `После отправки — письмо со ссылкой на личную страницу прогресса`

#### Добавить поля (кнопка «+ Add field»):

| Тип | Title (подпись) | Variable name | Required |
|-----|-----------------|---------------|----------|
| Input | Ваше имя | `parent_name` | да |
| Email | Email | `parent_email` | да |
| Input | Telegram (необязательно) | `parent_telegram` | нет |
| Input | Имя ребёнка | `child_name` | да |
| Number | Возраст ребёнка | `child_age` | нет |
| Select | Как присылать новости | `notification_channel` | да |
| **Hidden** | — | `module_id` | — |
| **Hidden** | — | `chosen_stage` | — |
| **Hidden** | — | `chosen_tale_number` | — |

**Hidden fields:** value оставьте **пустым** — Zero Block заполнит сам.

#### Select `notification_channel` — для КАЖДОЙ опции укажите Value:

| Title (видит родитель) | Value |
|------------------------|-------|
| На email | `email` |
| В Telegram | `telegram` |
| Email и Telegram | `both` |
| Только личная страница | `web` |

> В Tilda: клик по полю Select → список опций → у каждой опции поле **Value** (не путать с Title).

5. **Кнопка отправки:** `Оплатить` (см. шаг C7a — приём оплаты)
6. **Подпись под кнопкой:** `Безопасная оплата картой · после оплаты — письмо со ссылкой на личную страницу`
7. **Стиль блока:** фон `#FFFFFF`, скругление **16px**, лёгкая тень.

### Шаг C8. Webhook (корзина ST100)

1. Клик по блоку **ST100** → **Контент** → подключите **Webhook**.
2. Включите отправку на URL.
3. **URL:** `https://api.chitatelstvo.ru/webhook/register`
4. **Method:** POST
5. **Custom HTTP header:**
   - Name: `X-Webhook-Secret`
   - Value: *(скопируйте `WEBHOOK_SECRET` из `.env` на сервере — тот же, что для Tilda раньше)*
6. **Save**.

Tilda может отправить тест — ответ `ok` нормален.

## Если что-то не работает

| Симптом | Что проверить |
|---------|----------------|
| 404 на `/zapis` | Нажали **Опубликовать**? URL в SEO = `zapis`? |
| Zero Block пустой | HTML вставлен в элемент HTML внутри Zero? Сохранили Zero? |
| «Выберите класс…» при отправке | Выбраны класс + тариф на карточках |
| Нет письма | SMTP на сервере; `docker compose logs api` |
| 401 webhook | Неверный `X-Webhook-Secret` |
| Прогресс = только Колобок | В заявке нет `module_id` — проверьте 3 hidden в форме |
| Карточки не кликаются | Конфликт JS — опубликуйте и тестируйте не в редакторе, а на live |
