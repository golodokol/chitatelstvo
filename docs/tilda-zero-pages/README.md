## Как вставить страницу блога или статьи

1. Tilda → новая страница → Zero Block → HTML-элемент `</>`.
2. Ctrl+A → Delete → вставить файл целиком (`blog.html` или `12-voprosov-k-skazke.html`).
3. Артборд **1200**, высота **авто**, выравнивание сверху.
4. В настройках страницы заполнить Title / Description / адрес из `SEO-PUBLISH.md`.
5. Опубликовать.

**Важно:** сначала опубликуйте `/blog`, затем статью — или наоборот, но адрес статьи должен начинаться с `blog/…`.
