Готовые HTML (вставить целиком в HTML-элемент Zero Block).

| Страница | Файл | URL (предложение) |
|----------|------|-------------------|

| Читательская экспедиция | `expedition.html` | `/expedition` |

## Как вставить

1. Tilda → новая страница → Zero Block → HTML-элемент `</>`.
2. Ctrl+A → Delete → вставить файл целиком.
3. Артборд **1200**, высота **авто**, выравнивание сверху.
4. В настройках страницы заполнить Title / Description из комментария в начале файла.
5. Опубликовать.
