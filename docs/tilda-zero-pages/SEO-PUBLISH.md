## Как опубликовать в Tilda

1. **Страницы** → **Добавить страницу**.
2. Заполнить **Title / Description** из таблицы ниже (Настройки страницы → SEO).
3. Задать **адрес** страницы.
4. Добавить **Zero Block** → HTML-элемент `</>` → вставить **весь** файл.
5. Артборд **1200**, высота **авто**, выравнивание сверху.
6. Убрать лишние стандартные блоки Tilda (оставить Zero Block).
7. **Опубликовать**.
