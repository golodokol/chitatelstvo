## 0. Реквизиты · `/rekvizity` (для Яндекса / региона в Tilda)

Tilda **не принимает** `https://api.chitatelstvo.ru/...` в поле региональной принадлежности — нужна страница **на домене сайта**.

1. Новая страница → адрес `rekvizity`.
2. Zero Block → вставить `docs/tilda-zero-pages/rekvizity.html`.
3. Опубликовать.
4. В настройках сайта в поле «Ссылка на страницу… региональной принадлежности» указать:

```text
https://chitatelstvo.ru/rekvizity
```

| Поле | Значение |
|---|---|
| **Адрес** | `rekvizity` |
| **Title** | Реквизиты и контакты — Читательство |
| **Description** | Реквизиты ИП Рощина Ольга Владимировна, адрес в Москве, email и телефон онлайн-школы «Читательство». |
| **Keywords** | реквизиты Читательство, ИП Рощина, контакты Читательство, Москва |

## 1. Индекс блога · `/blog`

### Как добавить в Tilda

1. **Страницы** → **Добавить страницу**.
2. **Настройки страницы** → заполнить поля из таблицы ниже.
3. Удалить лишние стандартные блоки Tilda.
4. **Zero Block** → HTML-элемент `</>` → вставить **весь** файл  
   `docs/tilda-zero-pages/blog.html`.
5. Артборд **1200**, высота **авто**, выравнивание **сверху**.
6. **Опубликовать**.

### Данные для Tilda

| Поле в Tilda | Значение |
|---|---|
| **Название страницы** (в списке) | Блог |
| **Адрес страницы** (URL) | `blog` |
| **Полный URL** | https://chitatelstvo.ru/blog |
| **Title** (SEO) | Блог Читательства — статьи о чтении и сказках для родителей |
| **Description** (SEO) | Заметки о понимании текста, разговорах по сказкам и занятиях в онлайн-школе «Читательство». |
| **Keywords** | блог Читательство, статьи о чтении, сказки для родителей, понимание текста, литературное чтение |
| **Canonical** | https://chitatelstvo.ru/blog |
| **og:title** | Блог Читательства — статьи о чтении и сказках для родителей |
| **og:description** | то же, что Description |
| **og:image** | https://api.chitatelstvo.ru/assets/founder-olga.jpg |
| **H1 на странице** | Статьи о чтении и сказках |
