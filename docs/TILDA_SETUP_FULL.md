# Tilda: подробная настройка по модулям и урокам

> Автогенерация из `catalog/` и `lessons/catalog/`. Запуск: `python scripts/generate_tilda_setup_doc.py`

**API:** `https://api.chitatelstvo.ru`  
**Сайт:** `https://chitatelstvo.ru` (ваш домен Tilda)

---

## Главное: где что живёт

| Что | Где | Нужна страница Tilda? |
|-----|-----|----------------------|
| Запись на модуль | Форма на лендинге тарифа | **Да** — 18 страниц (6 групп × 3 тарифа) |
| Страница «Спасибо» | Success page формы | **Да** — 1 общая или 18 копий |
| Прогресс, баллы, кнопки уроков | `progress_url` на API | **Нет** — только ссылка с Tilda |
| Видео, квизы, творчество | Плеер на API | **Нет** — открывается с прогресса |
| Пилот «Колобок» | API, без `module_id` | Старая форма без скрытого поля |

**102 урока не требуют 102 страниц на Tilda.** На Tilda — только лендинги записи и маркетинг. Урок открывается по кнопке на личной странице прогресса.

## Часть 1. Один раз на весь сайт

### 1.1 Webhook (в настройках каждой формы записи)

| Параметр | Значение |
|----------|----------|
| URL | `https://api.chitatelstvo.ru/webhook/register` |
| Метод | POST |
| Заголовок | `X-Webhook-Secret` = значение из `.env` на сервере |

### 1.2 Обязательные поля формы (Variable name — точно так)

| Подпись для родителя | Variable name | Тип |
|----------------------|---------------|-----|
| Ваше имя | `parent_name` | text |
| Email | `parent_email` | email |
| Telegram (необяз.) | `parent_telegram` | text |
| Имя ребёнка | `child_name` | text |
| Возраст | `child_age` | number |
| Как присылать новости | `notification_channel` | select |

**Select `notification_channel`** — в value только код:

| Подпись | value |
|---------|-------|
| На email | `email` |
| В Telegram | `telegram` |
| Email и Telegram | `both` |
| Только личная страница | `web` |

### 1.3 Страница «Спасибо» (Success page)

Тексты — в `docs/TILDA_TEXTS.md` §3. Обязательно:
- объяснить, что ссылка на прогресс придёт на email / будет на странице;
- кнопка «На главную» → `https://chitatelstvo.ru`.

> Tilda не подставляет `progress_url` из ответа API автоматически — ссылка уходит в email и на личную страницу (канал `web`).

## Часть 2. Восемнадцать страниц записи (по одной на модуль)

Рекомендуемая структура URL на Tilda:

```
https://chitatelstvo.ru/zapis/{группа}/{тариф}
# пример: /zapis/1-klass/individualnoe
```

На каждой странице — **своя форма** (или копия шаблона) со **скрытым полем** `module_id`.

### Модуль 1: Разовое занятие, 1 класс

| | |
|---|---|
| **module_id** (скрытое поле) | `1` |
| Группа | 1 класс |
| Тариф | Разовое занятие |
| Цена (для текста) | 1490 ₽ |
| Сказок в модуле | 1 |
| Встреч с преподавателем | 1 |
| URL страницы (рекомендация) | `/zapis/1-klass/razovoe` |

**Шаги в Tilda:**

1. Создайте страницу (или скопируйте шаблон «Запись»).
2. Заголовок H1: **Разовое занятие, 1 класс**
3. Блок «Программа» — таблица сказок (см. ниже в Части 4 для этой группы).
4. Блок **Form** → добавьте поля из §1.2.
5. **Hidden field:** name=`module_id`, value=`1`.
6. Webhook — §1.1.
7. Success page — §1.3.
8. Кнопки с главной и страницы тарифа ведут **сюда**, не на общую форму.

**Дополнительно для разового занятия** — два видимых поля:

| Подпись | Variable name | Тип | value в option |
|---------|---------------|-----|----------------|
| Выберите этап | `chosen_stage` | select | `1` или `2` |
| Выберите сказку | `chosen_tale_number` | select | `1`, `2`, `3` или `4` |

**Опции select «Сказка»** — зависят от этапа. Варианты:

- **Простой:** два select; в подсказке написать «сначала этап, потом номер 1–4» и продублировать названия в блоке «Программа».
- **Удобный:** один select с двумя hidden-полями через Zero Block (см. Часть 3).
