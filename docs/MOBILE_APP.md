# Мобильное приложение «Читательство» — план и статус

Документ собирает подготовку к iOS/Android-приложению и отражает актуальное состояние на **август 2026**.

**Связанные файлы:** `mobile/` (Expo-клиент), `docs/WEBHOOK_AND_NOTIFICATIONS.md` (API), `docs/LESSON_PLAYER.md` (логика уроков).

---

## 1. Зачем приложение

| На вебе (Tilda + FastAPI) | В приложении |
|---------------------------|--------------|
| Запись и оплата | — остаётся на сайте |
| Комната приключений `/progress/{token}` | Нативный экран (уровень, Словики, сундук, расписание) |
| Уроки `/lesson/{slug}` | WebView по подписанной ссылке с сервера |
| Вход по ссылке из письма | **Email + OTP** → JWT → выбор ребёнка |
| Telegram / email уведомления | Лента «Для родителей» + email (push — позже) |

Приложение — **семейный кабинет после покупки**, не замена лендинга.

---

## 2. Что уже на проде (backend)

| Компонент | Статус | Путь |
|-----------|--------|------|
| OTP-вход | ✅ | `POST /api/v1/auth/otp/request`, `…/verify` |
| Сессия JWT | ✅ | `GET /api/v1/auth/me`, TTL 30 дней |
| JSON комнаты | ✅ | `GET /api/v1/cabinet?child_id=…` |
| JSON урока | ✅ | `GET /api/v1/lessons/{slug}` |
| Действия урока | ✅ | `POST /api/v1/lessons/{slug}/video-complete`, `…/quiz`, `…/emotion-quiz`, `…/manual`, `…/rating`, `…/retelling`, `…/quest-complete` |
| Сундук | ✅ | `POST /api/v1/chest/claim` |
| Старый вход | ✅ параллельно | `/progress/{token}`, подписанные `/lesson/…?sig=…` |

Общая логика кабинета: `services/cabinet.py` → `gamification/cabinet_ui.py` (один источник для HTML и JSON).

**Env:** `JWT_SECRET`, `OTP_TTL_SECONDS=600`, SMTP обязателен для кодов.

## 4. Курсы и уроки — что учитывать в приложении

### 4.1 Линейки на сайте ([chitatelstvo.ru](https://chitatelstvo.ru))

| Группа | Возраст | Страница | Формат урока |
|--------|---------|----------|--------------|
| `grade-1` … `grade-4` | 1–4 класс | `/1-klass` … `/4-klass` | сказка: видео + квизы |
| `extra-6-8`, `extra-9-11` | 6–8 / 9–11 лет | `/6-8-let`, `/9-11-let` | сказка |
| **`early-letters`** | 4–5(6) лет | `/bukvy-ozhivayut` | **квест** (станции, искорки) |
| **`early-stories`** | 5–7 лет | `/pervye-istorii` | **квест** + полка книжек |

Тарифы везде: `single` / `self_paced` / `with_teacher` (+ `trial` для early).

Оплата и запись — Tilda (`/oplata`, webhook `/webhook/register`). В приложении не дублируем.

### 4.2 Пробные уроки (лид с главной)

| Slug | Название | Станции |
|------|----------|---------|
| `early-letters-trial-lesson-01` | Словик и пропавшие звуки | Поляна шёпотов → Пещера эха → Мастерская буквы → … → сундук |
| `early-stories-trial-lesson-01` | Спаси первую историю | интерактивный маршрут по слогам и историям |

В кабинете для paid-треков без trial в enrollment подставляется intro-квест (`EARLY_INTRO_TRIALS` в `cabinet_ui.py`).

### 4.3 Модули «Первые шаги» (8 уроков)

Старт модуля: **1 сентября 2026**, новые уроки — **вторник и четверг**.

**«Буквы оживают»** — уроки 1–8: Мотор на поляне, Поющая У, Круглая О, Змейка, Рычит Р, Слоги дружат, Первые слова, Праздник у Словика.

**«Первые истории»** — уроки 1–8: Кот и коробка, Дождь за окном, Где мяч?, … Словик дома.

Каталог JSON: `lessons/catalog/early-*-stage-1-lesson-*.json`.

### 4.4 Школьные сказки (1–4 класс, внеклассное)

Расписание открытия (см. `services/cabinet.py` → `build_schedule_intro`):

- Сказки 1–2 — уже открыты
- 3–4 — с 31 августа
- 5–6 — с 7 сентября
- 7–8 — с 14 сентября
- Встречи с преподавателем — по четвергам (тариф `with_teacher`)

### 4.5 Два формата урока в плеере

| Формат | `lesson_format` | Шаги | Сундук |
|--------|-----------------|------|--------|
| **Сказка** | `tale` (по умолчанию) | видео ≥50% → эмоции → понимание → смысл → рейтинг | после video + comprehension + meaning |
| **Квест** | `quest` | станции с искорками, без длинного видео | после всех искорок (`quest-complete`) |

Квесты рендерятся в `templates/lesson_quest.html` + `static/lesson_quest.js/css`.  
**Мобильная вёрстка квестов** доработана (отдельные правила для `--puzzle`, `--build`, `--around`; см. `.cursor/rules/quest-layout-mobile-web.mdc`).

### 4.6 Геймификация (общая для веба и приложения)

- Валюта: **Словики** (не «баллы» в UI)
- Уровни: Старт → Юный читатель → Исследователь → Мастер слова → Литературный детектив
- Early-бейджи (пробные): Искатель искорок, Слоговик, Читатель, … — каталог `TRIAL_BADGE_CATALOG`
- Смешанные кабинеты: несколько enrollment-треков (`cabinet.tracks[]`), сортировка по доступу
- Повторная покупка: merge по `email + имя ребёнка`, один `progress_token`

## 5. Архитектура (актуальная)

```
Tilda (запись, оплата, лендинг)
        ↓ webhook
FastAPI (api.chitatelstvo.ru)
  ├── /progress/{token}     — веб-кабинет (HTML)
  ├── /lesson/{slug}        — веб-урок (HTML + JS)
  └── /api/v1/*             — JSON для приложения
        ↓ Bearer JWT
Expo (mobile/)
  ├── cabinet.tsx           — нативная комната
  └── lesson.tsx            — WebView на lesson_url
```

**Принцип:** бизнес-логика только на сервере; приложение — тонкий клиент. Уроки в v1 открываются через **WebView**, чтобы не переписывать квесты и Kinescope.

## 8. Чеклист проверки после изменений на сайте/уроках

При обновлении курсов или кабинета на вебе — проверить в приложении:

1. **OTP-вход** — email из базы, код приходит, JWT выдаётся
2. **Выбор ребёнка** — несколько детей на одном email
3. **Комната** — уровень, Словики, `continue_url`, tracks для смешанных курсов
4. **Early-квест** — пробный и модульный урок открываются в WebView, искорки и сундук работают
5. **Сказка 1–4 класс** — видео, квизы, начисление словиков
6. **Сундук** — `POST /api/v1/chest/claim`, переход к следующему уроку
7. **Родители** — расписание, шаги урока, таблица словиков
8. **Параллельный веб** — `/progress/{token}` по-прежнему работает
