# Яндекс: образовательные онлайн-курсы (YML-фид)

Документация: https://yandex.ru/support/webmaster/search-appearance/education.html

## Нам это подходит?

Да. Читательство — онлайн-курсы/уроки. В выдаче может появиться блок с курсами, ценой и ссылкой на страницу.

Уже есть: страницы курсов, цены, Метрика. Не хватает только **YML-фида** и загрузки в Вебмастер.

## Что сделать (порядок)

### 1. Категория из рубрикатора (уже проставлена)

```xml
<category id="10010" parentId="10000">Литература</category>
```

В генераторе: `CATEGORY_ID=10010`, родитель `10000`. Если найдёте более узкую категорию для «Буквы оживают» — можно задать отдельно в `CATEGORY_ID_EARLY`.

### 2. Собрать фид

```powershell
python scripts/gen_yandex_education_feed.py
```

Файл: `static/feeds/education.yml`  
Публичный URL после деплоя: `https://api.chitatelstvo.ru/feeds/education.yml`

В фиде по одному `offer` на курс (URL страницы на chitatelstvo.ru), цена модуля **1990 ₽**, формат «Самостоятельно», пробная часть отмечена.

### 3. Логотип площадки

Нужен **квадрат ≥ 100×100**, PNG или SVG.  
Сейчас логотип вытянутый — положите квадратный файл в  
`https://api.chitatelstvo.ru/assets/logo-chitatelstvo-square.png`  
и укажите его в генераторе (`SHOP_PICTURE`).

### 4. Загрузить в Яндекс Вебмастер

1. [webmaster.yandex.ru](https://webmaster.yandex.ru) → сайт chitatelstvo.ru (права подтверждены).
2. **Услуги и предложения в поиске** → **Фиды и ошибки** → **Загрузить фид**.
3. Категория бизнеса: **Образование**.
4. Регион: **Россия** (условия одинаковые).
5. Ссылка: `https://api.chitatelstvo.ru/feeds/education.yml`
6. Готово → дождаться проверки. Ошибки — справа у фида.

Проверка службой качества — несколько дней. Показ в поиске не гарантирован: влияет релевантность и ранжирование.

### 5. Метрика

Уже стоит. Для персонализации карточек Яндекс рекомендует Метрику — у нас ок.

## Важные правила фида

| Поле | Как у нас |
|------|-----------|
| `url` курса | Уникальный: `/1-klass`, `/bukvy-ozhivayut`… |
| `price` | 1990 (модуль). Разовое 799 — не отдельный offer без своей страницы |
| `Продолжительность` + `План` (≥3 пунктов) | Обязательны |
| `categoryId` | Только из рубрикатора Яндекса |
| Тариф «с преподавателем» | Отдельный offer только если будет **отдельный URL** |

## Сеты (наборы)

В фиде: «По классам», «Первые шаги», «Медленное чтение» — удобные подборки в ответе поиска.

## После правок цен/программ

Снова запустить генератор → задеплоить → Вебмастер подтянет файл сам (или обновить вручную).
