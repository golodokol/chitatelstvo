# Срочное восстановление главной в Tilda

## Что случилось

На опубликованной странице **пропал весь код** Zero Block (`chit-main` не найден).  
Сайт пустой — это не баг CSS, а **код не вставлен в то место** или **стёрся при редактировании**.

---

## Куда вставлять код (важно!)

Код из `00-tilda-lite.html` вставляется **не** в настройки сайта и **не** в отдельный блок T123 на странице.

### Правильно

1. Tilda → **Страницы** → откройте **главную**
2. Кликните по большому блоку **Zero Block** (весь лендинг)
3. Нажмите **Редактировать блок** (или двойной клик)
4. На холсте есть **один элемент** (иконка `</>` или «HTML»)
5. **Двойной клик** по этому элементу → откроется окно с кодом
6. **Ctrl+A** → **Delete** (удалить старое)
7. Вставьте **весь** файл `00-tilda-lite.html` (**Ctrl+A**, **Ctrl+C**, **Ctrl+V**)
8. Первая строка должна быть: `<!-- CHIT VERSION 20260620h`
9. Последняя строка: `chit-zero.js?v=20260620h`
10. **Сохранить** → **Опубликовать**

### Неправильно (так делать нельзя)

- Вкладки **CSS** и **JS** внизу Zero Block — **оставить пустыми** (для lite-версии)
- Отдельный блок **T123 HTML** на странице — не туда
- Настройки сайта → HTML-код — не туда
- Вставить только часть файла

## Настройки Zero Block (после вставки кода)

Клик по **пустому месту** холста (не по элементу):

| Параметр | Значение |
|----------|----------|
| Адаптировать к ширине окна | **ВЫКЛ** |
| Вертикальное выравнивание | **Верх** |
| Высота артборда | **35 000 px** или больше |
| Отступ сверху | **0** (убрать 60 px) |

У HTML-элемента на всех экранах (1200, 960, 640, 480, 320): **X=0, Y=0, ширина 100%**.

## Как проверить, что всё ок

1. В **редакторе** Zero Block после вставки видны шапка, заголовок, книги
2. После **Опубликовать** откройте `https://chitatelstvo.ru/` → **Ctrl+F5**
3. **Правый клик** → **Просмотр кода страницы** → поиск (`Ctrl+F`): `chit-main` — **должен найтись**
4. В коде должно быть: `chit-zero.js?v=20260620h`

Если `chit-main` не найден — код снова не в том месте или вставка обрезалась.
