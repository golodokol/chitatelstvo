# Докупка занятия с преподавателем (899 ₽)

Отдельный товар для учеников тарифа **«Индивидуальное»**, которые хотят добавить одну живую встречу к уже купленной сказке.

---

## 1. Создайте услугу в каталоге Tilda

**Каталог** → **+ Добавить услугу**:

| Поле | Значение |
|------|----------|
| Название | `Читательство · Занятие с преподавателем` |
| Цена | **899 ₽** |
| Артикул (SKU) | `SKU0004` |
| Количество | не 0 (в наличии) |

Скопируйте **Product ID** и **LID** (как для трёх основных тарифов в ST100_SETUP.md).

---

## 2. Блок ST205 на странице /oplata

На `chitatelstvo.ru/oplata` добавьте **четвёртый** блок **ST205** с Product ID новой услуги.

В поле «Название» вручную: `Читательство · Занятие с преподавателем`.

---

## 3. Пропишите ID в order-config.json

На сервере в `/var/www/chitatelstvo-assets/order-config.json` (или в репозитории `docs/tilda-zero-main/order-config.json`):

```json
"meeting_addon": {
  "uid": "ВАШ_PRODUCT_ID",
  "lid": "ВАШ_LID",
  "sku": "SKU0004",
  "title": "Читательство · Занятие с преподавателем",
  "price": 899
}
```

Поднимите `version` до **6** (уже в репозитории).

---

## 4. Скрытое поле в ST100 (главная и /oplata)

Добавьте Hidden-поле:

| Variable name |
|---------------|
| `lesson_slug` |

Используется при докупке встречи с урока (slug урока, например `grade-1-self_paced-stage-1-lesson-01`).

---

## 5. Webhook

При оплате докупки в webhook приходят:

- `module_id` = **19**
- `chosen_stage` = `1` или `2`
- `chosen_tale_number` = `1`–`4`
- `lesson_slug` = slug урока (желательно)

На бэкенде создаётся enrollment с `module_id=19` — после этого на странице урока показывается ссылка на встречу вместо кнопки «Записаться».

---

## 6. Страница докупки с урока

Кнопка на уроке ведёт на:

`https://api.chitatelstvo.ru/order/meeting?group=grade-1&stage=stage-1&tale=1&slug=...`

Оттуда — оплата 899 ₽ через `/oplata` (тариф `meeting_addon`).

---

## Проверка

1. Создали услугу 899 ₽ в Tilda и ST205 на /oplata  
2. Обновили `uid` / `lid` в order-config  
3. Оплатили тест — в админке enrollment с module_id=19  
4. На уроке блок «Живая встреча» переключился в режим ссылки
