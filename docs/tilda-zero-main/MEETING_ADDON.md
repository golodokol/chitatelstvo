## Про LID — не ищите отдельно

**LID** — второй числовой ID, который раньше был виден в старых карточках Tilda. Сейчас его часто **нет в интерфейсе** — это нормально.

Для корзины достаточно **Product ID** `168614126213`. В конфиге мы дублируем его в `lid` — оплата работает.

**Внешний код** `dBZzgmd0Rx8AmAY9ip7Y` — для интеграций Tilda, в корзину не подставляем.

## Пункт 4 — скрытое поле `lesson_slug` (простыми словами)

**Зачем:** когда родитель платит **799 ₽ с страницы урока**, системе нужно понять, **к какой сказке** привязать встречу.

**Что сделать в Tilda (5 минут):**

1. Откройте страницу **`/oplata`** (и при желании главную — тот же блок ST100).
2. Кликните блок **ST100** «Корзина с формой» → **Контент** → **+ Добавить поле**.
3. Тип: **Скрытое (Hidden)**.
4. **Variable name** (имя переменной): **`lesson_slug`** — латиницей, без пробелов.
5. Значение оставьте **пустым** — его подставит наш сайт при переходе с урока.
6. Опубликовать страницу.

Без этого поля оплата пройдёт, но в админке может не быть привязки к конкретному уроку.

Остальные скрытые поля (`module_id`, `chosen_stage`, …) у вас уже есть — **добавляется только одно новое**.

## Цена 799 ₽

В **каталоге Tilda** у услуги тоже поставьте **799 ₽** (не 899) — иначе в корзине Tilda покажет старую цену.

3. После оплаты в админке — запись с `module_id = 19`.
