# Картинки на Tilda CDN

Картинки с `api.chitatelstvo.ru` не всегда открываются с мобильных сетей.  
Решение: загрузить их **через редактор Tilda** — они попадут на `static.tildacdn.com`.

**Версия кода:** `20260621i`

> В Tilda **нет** пункта «Настройки сайта → Файлы».  
> Картинки заливаются через блок-галерею или Zero Block.

## Шаг 1. Загрузить картинки в Tilda (галерея GL12)

Папка с файлами: **`C:\Users\Оля\Desktop\TILDA-IMAGES`** (28 файлов).

1. [tilda.cc](https://tilda.cc) → проект **Читательство**
2. Откройте **любую страницу** (можно черновик «Служебная» — не главную)
3. Внизу страницы: **+ Добавить блок** → вкладка **«Галерея»** → блок **GL12** (или GL02)
4. Нажмите **Контент** у блока
5. **Загрузить файлы** → выделите всё из `TILDA-IMAGES` (Ctrl+A)
6. **Сохранить** страницу
7. Снова откройте **Контент** блока GL12 — у каждой картинки появится ссылка, начинается с `https://static.tildacdn.com/...`
8. Скопируйте ссылку на **любой** файл и проверьте базу, например:
   `https://static.tildacdn.com/tild3463-6531-4233-a632-616134353338/`
9. Блок GL12 можно **скрыть** (иконка глаза) — на сайте не виден, картинки на CDN остаются

Если база URL **другая** — напишите, перезапустим `scripts\apply_tilda_cdn.ps1` с новым адресом.

### Альтернатива (по одной)

Zero Block → **+** → **Image** → в настройках элемента **Upload file** / иконка **лупы** → загрузить файл с компьютера.

Для 28 картинок удобнее галерея GL12.
