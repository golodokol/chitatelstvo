# Связать каталог с оплатой (5 минут)

Если корзина открывается, но при «Оплатить» пишет **«товара нет в наличии»** — на сайте нет связи с каталогом Tilda. SKU (артикул) недостаточно, нужен **Product ID**.

## Важно: название Tilda НЕ подставляет сама

Официально ([help-ru.tilda.cc/online-store/one-product](https://help-ru.tilda.cc/online-store/one-product)):

> Из каталога синхронизируются **цена, артикул, количество, варианты**.  
> **Название и описание — вручную** в контенте блока.

Поэтому после Product ID нормально видеть:

| Поле | Откуда |
|------|--------|
| Зелёная плашка «товар связан» | каталог ✓ |
| Цена 1490 / 1990 / 4990 | каталог ✓ |
| SKU0001-2 … | каталог ✓ |
| **Studio Headphones** | **демо-шаблон — заменить руками** |
| Английский текст про headphones | **заменить руками** |

**Это не ошибка связи.** Product ID уже работает (у вас цена и SKU верные).

### Что сделать в каждом ST205

1. **Контент** → поле **«Название»** → удалить «Studio Headphones» → написать **точно как в каталоге**:
   - `Читательство · Разовое`
   - `Читательство · Индивидуальное`
   - `Читательство · С преподавателем`
2. **Описание** — свой текст про курс (или пусто).
3. Product ID **не трогать** — уже связан.
4. **Опубликовать**.

Символ **·** (точка по центру) между «Читательство» и тарифом — как в каталоге, не дефис и не пробел.

## Диагностика (проверено на chitatelstvo.ru)

| Признак | Сейчас на сайте | Должно быть |
|---------|-----------------|-------------|
| Product ID / цена / SKU | ✓ если 1490 и SKU0001-2 | совпадает с каталогом |
| Название в блоке | Studio Headphones | **вписать вручную** «Читательство · …» |
| Описание | демо на англ. | **вписать вручную** |

## Способ 1 — три блока ST205 (рекомендуем)

1. Откройте **главную** в редакторе Tilda.
2. **+ Блок** → **Магазин** → **ST205** «Карточка товара» — добавьте **3 блока**.
3. Поставьте их **внизу страницы** (под ST100) — на сайте они **автоматически скрыты** CSS Zero Block, видны только вам в редакторе.
4. Для каждого блока:
   - **Контент** → **ID товара в каталоге**
   - Откройте **Каталог** → кликните по услуге (не по таблице) → внизу **Product ID** (длинное число)
   - Вставьте в ST205:

   | ST205 | Услуга в каталоге | Цена |
   |-------|-------------------|------|
   | 1 | Читательство · Разовое | 1490 |
   | 2 | Читательство · Индивидуальное | 1990 |
   | 3 | Читательство · С преподавателем | 4990 |

5. **Опубликовать** главную.
6. Проверить оплату в режиме инкognito.

## Способ 1B — три блока «Товар» (T762)

Можно вместо ST205 — блок **Магазин → Товар** (на сайте `data-record-type="762"`).

**Важно после выбора Product ID:**

- На опубликованной странице должно быть **«Читательство · …»**, а не «Studio Headphones»
- Цена **1490 / 1990 / 4990**, а не **100**
- SKU **SKU0001-2 / SKU0002 / SKU0003**, а не «700.954.29»

Если видите демо-шаблон — откройте блок → **Контент** → заново выберите услугу из **Каталога** → **Опубликовать**.

**Пошагово для каждого из 3 блоков T762:**

1. Редактор → блок «Товар» внизу страницы  
2. **Контент** → поле «ID товара в каталоге» → **очистить** → снова выбрать услугу из списка каталога (клик по названию, не по таблице)  
3. В превью блока должно стать «Читательство · …» и нужная цена  
4. **Сохранить** блок → **Опубликовать** всю главную  
5. Открыть chitatelstvo.ru в инкognito → View Source → найти `rec2380183631` — там **не** должно быть `Studio Headphones` и `previewmode:'yes'`

Также обновите Zero Block: вставьте заново весь `00-tilda-lite.html` (версия `?v=20260609u`) → Опубликовать → Ctrl+F5.

## Способ 2 — прислать 3 Product ID

1. **Каталог** → **Экспорт** → CSV  
   или откройте каждую услугу и скопируйте Product ID.
2. Пришлите 3 числа — пропишем в `order-config.json` на сервере.

## Почему так

Tilda при оплате проверяет товар **только по Product ID из каталога**.  
Zero Block и SKU сами по себе эту связь не создают — её дают ST205 или Product ID в конфиге.
