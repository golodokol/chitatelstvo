# Связать каталог с оплатой (5 минут)

Если корзина открывается, но при «Оплатить» пишет **«товара нет в наличии»** — на сайте нет связи с каталогом Tilda. SKU (артикул) недостаточно, нужен **Product ID**.

## Способ 1 — три блока ST205 (рекомендуем)

1. Откройте **главную** в редакторе Tilda.
2. **+ Блок** → **Магазин** → **ST205** «Карточка товара» — добавьте **3 блока**.
3. Поставьте их **внизу страницы** (можно под ST100, можно скрыть визуально позже).
4. Для каждого блока:
   - **Контент** → **ID товара в каталоге**
   - Откройте **Каталог** → кликните по услуге (не по таблице) → внизу **Product ID** (длинное число)
   - Вставьте в ST205:

   | ST205 | Услуга в каталоге | Цена |
   |-------|-------------------|------|
   | 1 | Читательство · Разовое | 1490 |
   | 2 | Читательство · Индивидуальное | 1990 |
   | 3 | Читательство · С преподавателем | 4990 |

5. **Опубликовать** главную.
6. Проверить оплату в режиме инкognito.

## Способ 2 — прислать 3 Product ID

1. **Каталог** → **Экспорт** → CSV  
   или откройте каждую услугу и скопируйте Product ID.
2. Пришлите 3 числа — пропишем в `order-config.json` на сервере.

## Почему так

Tilda при оплате проверяет товар **только по Product ID из каталога**.  
Zero Block и SKU сами по себе эту связь не создают — её дают ST205 или Product ID в конфиге.
