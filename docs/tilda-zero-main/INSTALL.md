# Главная Tilda — Zero Block (быстрая установка)

Картинки уже на сервере: `https://api.chitatelstvo.ru/assets/`

## 1. Tilda — главная страница

1. Удалите/скройте старые блоки
2. **Добавить блок** → **Zero Block** (T123)
3. Ширина **1200px**, высота **авто**

## 2. Вставить код (Ctrl+A → Ctrl+C → Ctrl+V)

| Вкладка | Файл |
|---------|------|
| **HTML** | `01-html.txt` |
| **CSS** | `02-css.txt` |
| **JS** | `03-js.txt` |

**Все три вкладки обязательны.** Если вставить только `01-html.txt`, на сайте пропадут стили, программы сказок и форма записи (на странице не будет `chit-zero.js` / `buildAccordion`).

Альтернатива — один файл `00-tilda-zero-upload.html` (или `00-tilda-lite.html`) целиком в HTML-элемент Zero Block (CSS/JS грузятся с API). Собрать заново: `python scripts/build_tilda_upload.py`.

Сохранить → **Опубликовать**.

### Если сайт «сломался» после обновления HTML

1. Zero Block → вкладка **CSS** → вставьте `02-css.txt` целиком
2. Вкладка **JS** → вставьте `03-js.txt` целиком
3. **Опубликовать** → на сайте Ctrl+F5
4. Проверка: «Просмотр кода страницы» → поиск `buildAccordion` или `chit-zero.js` — должно найтись
5. После обновления дат курса обязательно **заново вставьте `03-js.txt`** во вкладку JS (или обновите `?v=` у ссылки на `chit-zero.js`, если JS грузится с API)

## 3. Шрифты

Сайт → Настройки → Шрифты: **Nunito**, **Literata**, **Caveat**

## 4. ST100 + оплата + webhook (обязательно!)

См. **`ST100_SETUP.md`** — поля формы, webhook, все 18 модулей.

### Важно про промокод

Скидку считает **Tilda**, не наш API. Чтобы код в форме Zero Block реально уменьшал сумму:

1. **Создайте промокод** в Tilda: Настройки сайта → Платёжные системы → Промокоды (например `ALFACHILDREN`).
2. **Включите «Промокоды» в ST100** на главной и на `/oplata`: блок ST100 → Настройки блока → переключатель **«Промокоды»** → Опубликовать. Без него кнопка покажет полную цену, скидка в корзине не сработает.
3. В ST100 добавьте скрытое поле **`promo_code`** (для webhook) — см. `ST100_SETUP.md`.

Проверка: ввести код на сайте → сумма на кнопке «Записаться» должна измениться. Подробный чеклист — в **`ST100_SETUP.md`**, раздел «Важно про промокод».
