# Страница оплаты /oplata (один раз, не на главной)

Вы правы: блоки на главной — тупик. T762 не работали, ST205 на главной — то же самое и портят вид.

**Решение:** отдельная страница `chitatelstvo.ru/oplata`. На главной **нет** карточек товара. Кнопка «Записаться» **перенаправляет** туда с уже заполненными данными.

---

## 1. Создайте страницу в Tilda

1. **Страницы** → **+ Новая страница**
2. Название: `Оплата` (или любое)
3. URL страницы: **`oplata`**
4. **Не добавляйте** в меню сайта

---

## 2. Блоки только на /oplata (не на главной)

Сверху вниз:

| Блок | Зачем |
|------|-------|
| **ST100** «Корзина с формой» | оплата + те же поля, что в ST100_SETUP.md |
| **ST205** × 3 | Product ID из каталога (1490 / 1990 / 4990) |
| **HTML** (T123) | скрипт ниже |

Product ID:

| Услуга | Product ID |
|--------|------------|
| Разовое 1490 | `797131986522` |
| Индивидуальное 1990 | `206548598642` |
| С преподавателем 4990 | `956231952022` |

В **Каталоге** у каждой услуги: **количество ≠ 0**.

**В каждом ST205 после Product ID** — вручную в поле «Название»:
`Читательство · Разовое` / `… Индивидуальное` / `… С преподавателем`  
(Tilda **не** подставляет название сама — только цену и SKU.)

ST100 на /oplata:
- те же поля (`parent_name`, `module_id`, …)
- webhook → `https://api.chitatelstvo.ru/webhook/register`
- Success URL → `https://api.chitatelstvo.ru/spasibo`
- Т‑Банк подключён

---

## 3. HTML-блок внизу /oplata

```html
<script src="https://api.chitatelstvo.ru/assets/chit-pay-page.js?v=3"></script>
```

Скрипт **скрывает карточки ST205** и сразу открывает корзину. На экране — только «Открываем корзину…», без ячеек «Разовое / Оплатить».

---

## 4. Главная страница

- Zero Block — вставить `00-tilda-lite.html` (`?v=20260609y`)
- **ST100 на главной можно убрать** (оплата только на /oplata)
- **Блоков ST205/T762 на главной — нет**

---

## 5. Опубликовать обе страницы

Главная → Записаться → переход на `/oplata` → корзина → Оплатить.

---

## Почему так

Tilda проверяет товар через каталог **на той же странице**, что и корзина. На главной без блоков каталога — «нет в наличии». На `/oplata` блоки ST205 **остаются в DOM**, но **скрыты** скриптом `chit-pay-page.js?v=3`.
