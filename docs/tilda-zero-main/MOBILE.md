# Мобильная версия главной (Tilda Zero Block)

## Настройки в редакторе Tilda

Откройте Zero Block (T123) на главной и проверьте:

### 1. Общие настройки артборда
- **Адаптировать к ширине окна** — **ВЫКЛ** (Autoscale OFF)
- **Контейнер** — **Grid** (не Window)
- Базовая ширина артборда: **1200 px**
- **Высота артборда:** **35 000 px** или больше (не 9500 — режет нижние секции)
- **Вертикальное выравнивание:** **верх** (Top), не Center

### 2. HTML-элемент на каждом брейкпоинте

Вверху редактора Zero Block переключайте экраны: **1200 → 960 → 640 → 480 → 320**.

Для **каждого** брейкпоинта у единственного HTML-элемента:

| Параметр | Значение |
|----------|----------|
| X | 0 |
| Ширина (W) | на всю сетку / 100% |
| Y | 0 |
| Высота (H) | auto (или большое число, JS подрежет) |

Если на 320/480 элемент остаётся шириной 1200 px и уезжает вправо — именно это и даёт «плывущую» вёрстку.

### 3. Код Zero Block
- Вставлен **`00-tilda-lite.html`** (CSS/JS с API)
- В ссылках версия **`?v=20260614f`** (или актуальная из файла)

### 4. Публикация и проверка
- **Опубликовать** страницу (не только сохранить в редакторе)
- На телефоне: жёсткое обновление или режим инкognito
- Проверять **опубликованный** URL, не превью редактора

## Что уже исправлено в CSS/JS (на сервере)

- На экранах ≤960 px отключён full-bleed `100vw` (убирает горизонтальный сдвиг)
- Tilda `transform: scale` сбрасывается — блок не сжимается как картинка
- Уменьшены отступы, заголовки, кнопки в шапке
- Блок «Записаться» без sticky-скролла на мобиле
- Карточки benefits без наклона, for-whom — иконка сверху

После обновления CSS/JS на API достаточно сменить `?v=…` в Zero Block и опубликовать.

---

## Если всё ещё «едет»

1. Убедитесь, что на странице **один** Zero Block (без дубликата HTML 2).
2. На брейкпоинте **320** откройте Zero Block — HTML должен быть **X=0, W=100%**.
3. Отключите «Адаптировать к ширине окна» ещё раз и сохраните.
4. Пришлите скрин с указанием брейкпоинта (320 / 375 / 414 px).
