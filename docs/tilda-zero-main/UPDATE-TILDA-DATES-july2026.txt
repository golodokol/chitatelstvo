ШАГ 1. HTML в Zero Block (обязательно — на сайте сейчас старые «29 июня»)
-------------------------------------------------------------------------
1. Tilda → главная страница → Zero Block (T123)
2. Вкладка **HTML** → Ctrl+A → удалить → вставить **целиком** файл:

   docs/tilda-zero-main/01-html.txt

3. Сохранить


ШАГ 2. JS на сервере (после git push + deploy)
----------------------------------------------
Скрипт chit-zero.js обновляется автоматически при deploy_quick.ps1.
В конце HTML Zero Block (если есть строка подключения) смените версию для сброса кэша:

   chit-zero.js?v=20260708

   (было, например: ?v=20260624a)


ШАГ 3. Быстрая правка без полной вставки HTML (если удобнее)
------------------------------------------------------------
В HTML Zero Block найти и заменить:

   29 июня        →  6 июля
   Старт 20 июля  →  Старт 27 июля   (кнопки и подписи второго этапа)
   20 июля        →  27 июля         (только там, где речь о старте второго блока)

Проверьте вручную: в тексте про «12 сказок» должно быть «старт 6 июля, продолжение 27 июля».


ШАГ 4. Опубликовать
-------------------
Опубликовать страницу в Tilda → обновить главную с Ctrl+F5.
