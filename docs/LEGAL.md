Документы для соответствия 152-ФЗ и дистанционной продаже услуг (ИП Рощина О.В.).

## Страницы на API (уже работают после деплоя)

| Документ | URL |
|----------|-----|
| Политика конфиденциальности | https://api.chitatelstvo.ru/legal/politika |
| Публичная оферта | https://api.chitatelstvo.ru/legal/oferta |
| Реквизиты | https://api.chitatelstvo.ru/legal/rekvizity |

Шаблоны: `templates/legal/`. Роуты: `api/routes/legal.py`.

## Футер на главной (Zero Block)

Ссылки добавлены в `01-html.txt` / `00-tilda-lite.html`. После обновления Zero Block на Tilda внизу страницы появятся:

- Политика конфиденциальности  
- Публичная оферта  
- Реквизиты  
- info@chitatelstvo.ru · +7 (958) 500-08-50  
- ИП Рощина Ольга Владимировна · ИНН 231150315327  

Пересборка lite-версии:

```bash
python scripts/build_tilda_lite.py
```

Загрузите обновлённый `chit-zero.css` на сервер:

```bash
cp docs/tilda-zero-main/chit-zero.css /var/www/chitatelstvo-assets/
```
