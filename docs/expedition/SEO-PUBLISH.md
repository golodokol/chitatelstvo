## Интерактивный прототип (сейчас)

После деплоя API страницы открываются так:

| URL | Страница |
|-----|----------|
| `/expedition` | Главная |
| `/expedition/map` | Карта |
| `/expedition/routes` | Маршруты |
| `/expedition/passport` | Паспорт читателя |
| `/expedition/libraries` | Библиотекам |
| `/expedition/add-legend` | Предложить легенду |
| `/expedition/about` | О проекте |
| `/expedition/kit.html` | Сценарий встречи для печати |

Локально: `uvicorn api.main:app --reload` → http://localhost:8000/expedition

Презентация: `docs/presentations/expedition.html` (стрелки клавиатуры, `?pdf` для экспорта).

## Страница на Tilda: `/expedition`

1. **Страницы** → **Добавить страницу**.
2. Заполнить Title / Description из таблицы.
3. Адрес страницы: `expedition`.
4. Zero Block → HTML-элемент `</>` → вставить `docs/tilda-zero-pages/expedition.html`.
5. Артборд **1200**, высота **авто**, выравнивание сверху.
6. Опубликовать.

Вложенные адреса (`/expedition/map` и дальше) на Tilda удобнее открывать через хеш (`#/map`) или с API, пока на сайте нет прокси.

| Поле в Tilda | Значение |
|---|---|
| **Название страницы** | Читательская экспедиция |
| **Адрес** | `/expedition` |
| **Title** | Читательская экспедиция — литературная школа «Читательство» |
| **Description** | Интерактивное путешествие по сказкам, героям и легендам народов России от литературной школы «Читательство». |
| **Keywords** | читательская экспедиция, сказки народов России, литературная школа, Читательство, библиотеки |
| **Canonical** | https://chitatelstvo.ru/expedition |
| **og:image** | https://api.chitatelstvo.ru/static/expedition/images/hero-map.png |
| **H1** | Читательская экспедиция |
| **Файл** | `docs/tilda-zero-pages/expedition.html` |

## Что в прототипе

- 10 регионов на карте, 12 карточек историй, 3 маршрута
- паспорт и 8 бейджей (в той же игровой логике школы)
- формы «Библиотека-партнёр», «Предложить легенду», «Сообщить об ошибке»
- сценарий встречи «Литературные детективы: тайны сказки»

Заявки пишутся в `data/expedition/` на сервере. SQL-заготовка: `db/migrations/004_expedition.sql`.
