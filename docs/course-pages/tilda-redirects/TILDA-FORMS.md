# Формы и уведомления Tilda — пошагово

Две разные формы. Не путайте имена.

| Где | Имя формы (точно) | Зачем |
|-----|-------------------|-------|
| Страницы курсов 1–4 класс, 6–8, 9–11 | **`Жду с преподавателем`** | Когда тариф «С преподавателем» закрыт — родитель оставляет email и телефон |
| Главная `chitatelstvo.ru` | **`Консультация`** | Блок «Сделайте первый шаг» — помощь с выбором курса без квиза |

---

## А. Страницы курсов (нет продаж «с преподавателем»)

**Страницы:** `/1-klass`, `/2-klass`, `/3-klass`, `/4-klass`, `/6-8-let`, `/9-11-let`

На каждой из этих **6 страниц** сделайте одно и то же.

### 1. Где добавить

1. Откройте страницу в редакторе Tilda (например `1-klass`).
2. **Ниже** Zero Block с курсом нажмите **«+»** → добавьте блок **Form** (любой простой: BF301 / BF002 — не важно).
3. Форму **не** кладите внутрь Zero Block.

### 2. Что настроить у формы

1. Клик по блоку формы → **Контент** / шестерёнка формы.
2. **Название формы** (Form name) = ровно:

   ```
   Жду с преподавателем
   ```

3. Поля (оставьте только эти, лишние удалите):

   | Подпись на форме | Тип поля | Переменная (имя) |
   |------------------|----------|------------------|
   | Email | Email | `Email` |
   | Телефон | Phone | `Phone` |
   | Курс (можно скрыть) | Input или Text area | `course` |

   Поле `course` необязательно, но удобно: скрипт подставит туда «1 класс» и т.п.

4. Кнопка «Отправить» может остаться — её посетитель не увидит (форму скроете).

### 3. Уведомления вам на почту

1. В настройках **этой же** формы → раздел **«Получать заявки»** / **Services** / **Уведомления**.
2. Включите **Email** на ваш адрес (тот, куда Tilda шлёт заявки).
3. Сохраните.

Без этого шага заявка в Tilda может сохраниться, но письмо не придёт.

### 4. Скрыть форму с экрана

Форма должна **остаться на странице**, но быть невидимой:

- Контекстное меню блока → **Скрыть блок**  
  **или**
- Высота блока ≈ 0 / уехать за край экрана.

Не удаляйте блок. Не отключайте форму.

### 5. Опубликовать

**Опубликовать** страницу. Повторить для всех 6 страниц курсов.

### Как проверить

1. Откройте `/1-klass` → тариф «С преподавателем» → «оставить контакты».
2. Введите свой email и телефон → Отправить.
3. Должно прийти письмо от Tilda с формой «Жду с преподавателем».

## Б. Главная: помощь с выбором курса (без квиза)

**Страница:** главная `chitatelstvo.ru`  
**Блок на сайте:** секция `#lead` — «Сделайте первый шаг» / «Получить консультацию»  
(это **не** квиз; квиз — отдельное окно «Попробовать бесплатно»).

### 1. Где добавить

1. Откройте **главную** в Tilda.
2. **Ниже** большого Zero Block (или внизу страницы, до футера сайта) → **«+»** → блок **Form**.
3. Снова: форма **рядом** с Zero Block, не внутри HTML Zero Block.

### 2. Что настроить у формы

1. **Название формы** = ровно:

   ```
   Консультация
   ```

2. Поля:

   | Подпись | Тип | Переменная |
   |---------|-----|------------|
   | Имя | Name / Input | `Name` |
   | Email | Email | `Email` |
   | Телефон | Phone | `Phone` |
   | Возраст ребёнка | Input | `Input_2` или `age` |
   | Комментарий | Text area | `Textarea` или `Comments` |

3. Уведомления на email — **включить** (как в разделе А.3).
4. Скрыть блок (как в А.4).
5. **Опубликовать** главную.

### 3. Как проверить

1. На главной прокрутите до «Сделайте первый шаг».
2. Заполните форму → «Получить консультацию».
3. Должно прийти письмо Tilda с формой «Консультация» (не только mailto).

Если скрытой формы нет — откроется запасной mailto на `info@chitatelstvo.ru`.

---

## Важно

1. **Имена форм** должны совпадать **буква в букву** (скрипт ищет по ним).
2. На курсах и на главной — **две разные** формы с **разными** именами.
3. Корзину / оплату (ST100, Cart) **не трогайте** — это другие формы.
4. После добавления форм на курсах Zero Block с HTML курса уже умеет отправлять заявки (версия ассетов с waitlist). На главной нужен актуальный `chit-zero.js` с отправкой в форму «Консультация».
