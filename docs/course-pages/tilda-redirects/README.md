# Страницы-редиректы в Tilda (5 минут на страницу)

Каждый файл здесь — **готовый HTML** для блока T123 на `chitatelstvo.ru`.

## Создать страницу в Tilda

1. **Страницы** → **+ Новая страница** → пустая
2. **Настройки страницы** → SEO → **URL страницы** — см. таблицу
3. Снять галочку **«Показывать в меню»** (или добавить в меню — по желанию)
4. **+ Блок** → **Другое** → **T123 HTML**
5. Вставить содержимое соответствующего `.html` файла из этой папки
6. **Опубликовать**

## После публикации

1. Обновите главную: в Zero Block уже стоят ссылки на `chitatelstvo.ru/1-klass` … (версия JS `20260709g` на сервере).
2. Проверьте: главная → «Сказки по классам» → раскрыть «1 класс» → **Подробнее о курсе** → открывается лендинг курса.
3. На лендинге → **Записаться** → `chitatelstvo.ru/oplata`.

Главную **перевставлять не нужно**, если на сайте подключён `chit-zero.js?v=20260709g` с API.
