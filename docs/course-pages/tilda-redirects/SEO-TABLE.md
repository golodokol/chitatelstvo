# SEO и файлы для 12 страниц курсов

Папка файлов: `docs/course-pages/tilda-redirects/`

**Версия ассетов Zero Block:** `20260824m`

В Tilda: **Page Settings → SEO** → Title / Description / Keywords.  
**Social / OG** — выровнять с SEO (таблица в `OG-PAGE-SETTINGS.md`).  
Затем **Zero Block** → вставить файл целиком → высота артборда **авто** → Опубликовать.

В Zero Block уже вшиты JSON-LD: **Course + Offer**, **FAQPage**, **BreadcrumbList**.
