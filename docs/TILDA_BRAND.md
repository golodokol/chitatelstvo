# Бренд «Читательство» — цвета и оформление для Tilda

Палитра снята с логотипа: **пыльный голубой**, **тёплый крем**, **золотая звезда** на белом.

---

## Палитра

| Роль | HEX | Где использовать |
|------|-----|------------------|
| **Голубой основной** (книга, текст лого) | `#88A9D1` | Акценты, иконки, вторичные кнопки, рамки hover |
| **Голубой тёмный** (кнопки, текст заголовков) | `#5B7FA6` | Primary-кнопки, активные pills, заголовки H1–H2 |
| **Голубой глубокий** (основной текст) | `#3D5266` | Параграфы, подписи форм |
| **Голубой приглушённый** | `#6B8499` | Вторичный текст, подсказки |
| **Золото звезды** | `#E9B85B` | Метки «Шаг 1», бейджи, акценты, hover-рамки |
| **Золото светлое** | `#F5E6C8` | Фон блока «Ваш выбор», подсветка |
| **Крем страниц** | `#F9EFE1` | Фон секций, фон страницы |
| **Крем тёплый** | `#F5EDE3` | Альтернатива фона блоков |
| **Белый** | `#FFFFFF` | Карточки тарифов, форма |
| **Рамки** | `#D4E2EF` | Обводки pills и карточек |

---

## Шрифты (Tilda → Настройки сайта)

| Роль | Шрифт | Почему |
|------|-------|--------|
| Заголовки | **Nunito** (600–700) или **Montserrat** | Мягкие округлые формы, как в лого |
| Текст и формы | **Nunito** (400) или **PT Sans** | Читаемость, кириллица |

**Не использовать** Georgia / Playfair — в логотипе sans-serif, serif будет «чужим».

## Фоны секций на `/zapis`

Чередование для ритма страницы:

```
Обложка      → #F9EFE1 (крем) или фото + overlay #F9EFE1 85%
Программы    → #FFFFFF
Тарифы       → #F9EFE1
Zero Block   → #FFFFFF
Форма        → #FFFFFF в карточке на #F9EFE1
FAQ          → #FFFFFF
```

## Accordion «Программы»

- Заголовок вкладки активной: текст `#5B7FA6`, линия `#E9B85B`
- Фон открытой вкладки: `#F9EFE1`
- Таблицы: шапка `#E8F1F8`, текст `#3D5266`

## Логотип на странице

- **Шапка сайта (ME401):** логотип слева, меню справа, фон `#FFFFFF` или прозрачный на креме
- **Обложка `/zapis`:** логотип над H1, высота ~80–100 px
- Формат: PNG на белом или SVG — на кремовом фоне белая подложка не нужна
