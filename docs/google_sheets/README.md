# Шаблон Google Sheets — модули и уроки «Читательство»

Готовые CSV-файлы для импорта в Google Таблицы. В них уже размечены **16 модулей** и **60 уроков** — вам нужно заполнить названия сказок и уроков.

---

## Файлы в этой папке

| Файл | Что внутри |
|------|------------|
| `МОДУЛИ.csv` | 16 модулей (4 класса × 4 тарифа) |
| `УРОКИ.csv` | 60 уроков — **основной лист для заполнения** |
| `СПРАВОЧНИК_БЕЙДЖИ.csv` | Подсказка по бейджам (не редактировать обязательно) |

---

## Как создать таблицу в Google Sheets (5 минут)

### Шаг 1. Создать новую таблицу

1. Откройте [Google Таблицы](https://sheets.google.com).
2. Создайте пустую таблицу.
3. Назовите её, например: **Читательство — каталог модулей**.

### Шаг 2. Импортировать лист «УРОКИ»

1. **Файл → Импорт → Загрузка**.
2. Выберите `УРОКИ.csv` с компьютера.
3. В настройках импорта:
   - **Место импорта:** «Заменить текущий лист» (для первого файла).
   - **Разделитель:** «Определять автоматически» или «Запятая».
4. Нажмите **Импортировать данные**.
5. Переименуйте лист внизу: **УРОКИ**.

### Шаг 3. Добавить лист «МОДУЛИ»

1. Внизу нажмите **+** (новый лист).
2. **Файл → Импорт → Загрузка** → выберите `МОДУЛИ.csv`.
3. **Место импорта:** «Вставить новый лист(ы)».
4. Переименуйте лист: **МОДУЛИ**.

### Шаг 4. (По желанию) Справочник бейджей

То же самое с `СПРАВОЧНИК_БЕЙДЖИ.csv` → лист **БЕЙДЖИ**.

### Шаг 5. Закрепить шапку

На листе **УРОКИ**: выделите строку 1 → **Вид → Закрепить → 1 строку**.

## Что заполнять вам

### Лист УРОКИ — главная работа

Заполните **два столбца** (остальное можно позже):

| Столбец | Пример | Подсказка |
|---------|--------|-----------|
| **Название урока (заполнить)** | `Урок 1: Колобок` | Как увидит родитель на сайте |
| **Сказка (заполнить)** | `Колобок` | Короткое имя сказки для прогресса и бейджей |

Рекомендуемый формат названия урока:

```
Урок 1: Колобок
Урок 2: Репка
Урок 3: Теремок
```

Для разового занятия достаточно одной строки на модуль.  
Для индивидуального — 4 строки.  
Для модуля с преподавателем — 3 обязательных + 4-й опциональный.  
Для летнего — 4 обязательных + 5–6 опциональные (см. столбец «Примечание»).

### Лист МОДУЛИ — сводка по сказкам

Столбец **Список сказок (заполнить)** — перечислите сказки модуля через запятую:

```
Колобок, Репка, Теремок, Лиса и журавль
```

Это удобно для обзора; детали всё равно дублируются на листе УРОКИ.

### Позже (не сейчас)

| Столбец | Когда заполнять |
|---------|-----------------|
| Видео (ссылка) | После съёмки |
| Рабочий лист (ссылка) | После подготовки PDF |
| Задания (текст) | При написании сценария |
| Статус | `черновик` → `активен`, когда урок готов |

## Удобные приёмы в Google Sheets

### Фильтр по классу

1. На листе **УРОКИ** выделите всю таблицу.
2. **Данные → Создать фильтр**.
3. В столбце **Класс** выберите нужный класс (1, 2, 3 или 4).

### Подсветка пустых ячеек

1. Выделите столбцы **Название урока** и **Сказка**.
2. **Формат → Условное форматирование**.
3. Правило: «Ячейка пуста» → светло-жёлтый фон.

Так сразу видно, что ещё не заполнено.

### Столбец Slug — не менять

`grade-1-self_paced-lesson-01` и подобные — технические имена для сайта. Они уже согласованы с будущим кодом. Менять только если переименовываете структуру целиком.

## Чеклист перед передачей в Cursor

- [ ] Все 60 строк: столбец **Сказка** заполнен (или помечены опциональные как «—» / «не используем»)
- [ ] Все 60 строк: столбец **Название урока** заполнен
- [ ] На листе **МОДУЛИ**: столбец **Список сказок** заполнен для каждого модуля
- [ ] Таблица доступна по ссылке (хотя бы «все, у кого есть ссылка — просмотр»)

Когда будет готово — пришлите ссылку на таблицу или экспортируйте **УРОКИ.csv** и **МОДУЛИ.csv** обратно в эту папку. Cursor импортирует данные в `catalog/modules.json` и файлы уроков.
