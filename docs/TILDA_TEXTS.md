Готовые блоки для копирования. **Читательство** — литературная школа онлайн для детей 7–10 лет.  
Тон: тепло, без давления, для родителей.

**Замените в текстах:**
- `https://ВАШ_ДОМЕН` — адрес API и личных страниц

- `YourSchoolBot` — username Telegram-бота

**Заголовок:** Кому подойдёт Читательство

- Семье, где гаджеты побеждают книгу

### Блок «Как устроен модуль»

**Заголовок:** Один модуль — четыре недели

| | |
|---|---|
| **3–4 сказки** | Каждая — отдельный мини-курс |
| **1 видео = 1 сказка** | Смотрите в удобное время |
| **Рабочий лист** | Коротко, по делу, на 15–20 минут |
| **Задания** | Понимание и смысл — **баллы сами**; творчество — с отметкой родителя |
| **Живая встреча** | Раз в неделю — обсудить и поиграть |

Видео и ответы на вопросы в интерактивном уроке засчитываются **автоматически** — родителю не нужно заполнять формы после каждого шага. Ребёнок идёт в своём темпе. Пропустил день — ничего страшного.

## 2. Страница регистрации

**Запись в Читательство**

### Вводный текст

Заполните форму — мы создадим личную страницу прогресса и пришлём ссылку на первый урок.

Занятия бесплатны в рамках набора / укажите стоимость, если платно.

### Подписи к полям формы

| Поле | Подпись |
|------|---------|
| parent_name | Ваше имя |
| parent_email | Email для новостей о прогрессе |
| parent_telegram | Telegram (необязательно) |
| child_name | Имя ребёнка |
| child_age | Возраст ребёнка |
| notification_channel | Как присылать новости о занятиях |

### Подсказка под выбором канала

- **Email** — письма с прогрессом и ссылкой на страницу
- **Telegram** — после записи привяжете бота в один клик
- **Email и Telegram** — дублируем важное
- **Только личная страница** — без писем; сохраните ссылку в закладки

### Текст согласия (под формой)

Нажимая «Отправить», вы соглашаетесь на обработку данных для занятий в Читательстве. Мы не передаём данные третьим лицам и не рассылаем рекламу.

## 7. Страница «Как это работает»

### Заголовок

**Как устроено Читательство — простыми словами**

### Текст

**1. Регистрация**  
Форма на сайте → личная страница прогресса по персональной ссылке.

**2. Урок по сказке**  
На странице прогресса — кнопка сказки. Открывается **интерактивный плеер**: видео (Kinescope) и вопросы в одном месте.

**3. Баллы автоматически**  
- Досмотрел видео → +2 балла  
- Ответил на вопросы о тексте → +2 балла  
- Ответил о смысле сказки → +2 балла  

Родителю **не нужно** заполнять формы после каждого шага.

**4. Вручную — только два раза**  
Творческое задание и живая встреча — одна кнопка внизу плеера.

**5. Новости родителю**  
Короткое сообщение на странице прогресса, в email или Telegram.

**6. Живая встреча**  
Раз в неделю — обсудить сказку вместе. Необязательно, но помогает.

### FAQ

**Нужно ли отмечать, что ребёнок посмотрел видео?**  
Нет. Плеер Читательства засчитывает просмотр сам, когда досмотрели достаточно.

**Нужно ли отправлять форму после заданий?**  
Нет, для видео и вопросов — всё автоматически. Форма не нужна.

**Когда родителю что-то нажимать?**  
Только когда ребёнок сделал **творческое задание** или был на **живой встрече** — кнопки внизу урока.

**Нужно ли делать всё за один день?**  
Нет. Модуль на неделю, можно в своём темпе.

**Ребёнок ошибся в квизе?**  
Можно попробовать снова. Мы хвалим усилие, не ругаем.

**Обязателен ли Telegram?**  
Нет. Достаточно страницы прогресса или email.

**Сколько времени в день?**  
Обычно 15–30 минут.

**Работает ли с телефона?**  
Да. Плеер и страница прогресса — с телефона и планшета.

**Почему видео не грузится?**  
Уроки Читательства на российском хостинге (Kinescope) — VPN не нужен. Если проблема — напишите нам.
