## 5. Блок 5 — Форма Tilda

Расположите **сразу под** Zero Block. В Zero hidden-поля должны иметь **те же name**, что Variable name в форме, **или** форма и Zero в одном `<form>` — проще связать через JS (см. html-файл).

### Поля формы

| Подпись | Variable name | Стиль |
|---------|---------------|-------|
| Ваше имя | `parent_name` | полная ширина |
| Email | `parent_email` | полная ширина |
| Telegram | `parent_telegram` | необяз., placeholder `@username` |
| Имя ребёнка | `child_name` | половина |
| Возраст | `child_age` | половина |
| Как присылать новости | `notification_channel` | select |
| *(hidden)* | `module_id` | из Zero Block |
| *(hidden)* | `chosen_stage` | из Zero Block |
| *(hidden)* | `chosen_tale_number` | из Zero Block |

**Select notification_channel** — value: `email`, `telegram`, `both`, `web`.

**Настройки формы → Стиль:**
- Фон блока `#FFFFFF`, скругление 16px, тень лёгкая
- Заголовок формы: `Контактные данные`
- Подзаголовок: `Укажите контакты и перейдите к оплате`

**Кнопка:** `Оплатить`

**Оплата:** **Т‑Банк** через блок **ST100** (корзина). Инструкция: `docs/TILDA_PAYMENT_TBANK.md`. Обычная форма BF503 с оплатой **не работает** с Т‑Банком.

**Webhook** (после успешной оплаты):
```
URL: https://api.chitatelstvo.ru/webhook/register
Header: X-Webhook-Secret: …
```

**Before submit (важно):** в Zero Block скрипт проверяет, что `module_id` заполнен — иначе alert «Выберите класс и формат выше».

## 6. Блок 6 — FAQ (3 вопроса)

**Заголовок:** `Частые вопросы`

**Accordion AR01N** (4 пункта):

1. **Нужно ли сдавать задания родителю?** — Нет, видео и квизы засчитываются в плеере. Творчество — одна кнопка, когда ребёнок сделал.
2. **Можно в своём темпе?** — Да. Новая сказка открывается раз в неделю, внутри недели — как удобно.
3. **Чем отличаются форматы?** — Разовое: 1 сказка (1 490 ₽). Индивидуальное: 4 сказки одного периода (1 990 ₽). С преподавателем: 4 сказки + 4 встречи (4 990 ₽). Период — 22 июня или 20 июля.
4. **Где смотреть прогресс?** — На личной странице по ссылке из письма. Можно только web, без email.

## 8. Связка Zero Block ↔ Form (Business)

Скрипт в `tilda_zero_zapis.html` каждые 500 ms копирует hidden-значения в поля формы Tilda:

```javascript
['module_id', 'chosen_stage', 'chosen_tale_number'].forEach(function (name) {
  var src = document.getElementById(name);
  var dst = document.querySelector('.t-form input[name="' + name + '"]');
  if (src && dst) dst.value = src.value;
});
```

В форме Tilda добавьте **3 hidden fields** с этими Variable name (пустой value).
