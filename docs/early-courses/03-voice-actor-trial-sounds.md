# ТЗ чтецу: все звуки пробных занятий

**Проект:** Читательство  
**Персонаж:** Словик (голос проводника) + учебные звуки/слоги/слова тем же голосом  
**Уроки:** пробные «Буквы оживают» и «Первые истории»  
**Дата фиксации:** 16.08.2026

Вступительные ролики 35–45 сек — в отдельном файле `01-voice-actor-intro` (`bo-trial-intro`, `ph-trial-intro`).  
Здесь — **все короткие реплики и учебные звуки станций** после intro.

---

## Общие требования

| Параметр | Значение |
|---|---|
| Роль | Словик — тёплый проводник; для учебных звуков — чисто, без «эм/эс» |
| Слушатель | 4–7 лет, рядом взрослый |
| Тон реплик | спокойный, чуть игривый; 5–12 слов |
| Тон звуков/слогов | ровно, разборчиво, без театра |
| Нельзя | сюсюканье, крик, музыка на дорожке, названия букв «эм», «эс», «а» как имя буквы — только звук |
| Пауза | 0,3–0,5 сек в конце файла |
| Дубли | 1 основной + 1 запасной на каждую реплику |
| Формат | WAV 48 kHz / 24-bit **или** 44.1 kHz; моно; имя = колонка «файл» |
| Папки сдачи | `bo-trial/` и `ph-trial/` (+ общая `shared/` для универсальных) |

Перед блоком реплик: *«Я Словик. Коротко, тепло, зову помочь.»*  
Перед блоком звуков: *«Только звук, чисто, без лишних слов.»*

### Типы файлов

| Метка | Что это |
|---|---|
| **VO** | реплика Словика |
| **SND** | учебный звук / слог / слово голосом чтеца |
| **SFX\*** | звук мира: можно имитацией чтеца *или* библиотекой; если чтец — имитировать мягко |

## D. Сводка количества файлов

| Блок | Примерно файлов |
|---|---:|
| Shared | 10 |
| Буквы оживают (станции, без intro) | ~35 |
| Первые истории (станции, без intro) | ~35 |
| Intro (отдельное ТЗ) | 2 |
| **Всего ориентир** | **~80** |

Можно писать **пакетами за один день**:  
1) shared → 2) все SND/SFX → 3) VO станций «Буквы» → 4) VO станций «Истории».

## E. Важные произношения (шпаргалка чтецу)

| Пишем | Говорим | Не говорим |
|---|---|---|
| звук М | м-м-м | эм |
| звук С | с-с-с | эс |
| звук А | а-а-а | «буква а» длинно и назидательно |
| слог МА | ма | мэ-а / эм-а |
| слог СО | со | эс-о |
| мама | ма-ма (ровно) | мааама театрально |
| кот спит | кот спит (две ровные части) | скороговорка |

## G. Контекст станций (не читать в микрофон)

**Буквы оживают:** Врата страны звуков → Поляна шёпотов → Пещера эха → Мастерская буквы → Охота на А → Корзина слов → Мост дружбы → Пауза в траве → Финишный сундук → Награда Словика.

**Первые истории:** Закрытая книжка → Камни букв → Звуковая тропа → Поляна слогов → Пауза на тропе → Домик слов → Окно истории → Ключ от книжки → Награда Словика.
