# ТЗ чтецу: два пробных урока

**Проект:** Читательство  
**Персонаж:** Словик  
**Дата:** 21.08.2026  

В одном файле — две сессии записи:

1. **«Буквы оживают»** — урок «Словик и пропавшие звуки»  
2. **«Первые истории»** — урок «Спаси первую историю»  

Короткие реакции («Правильно!», «Есть!» …) можно записать **один раз** в сессии «Буквы» и переиспользовать во «Историях» (другие имена файлов: `ph-vo-…`).

# Часть 1. «Буквы оживают»

**Урок:** «Словик и пропавшие звуки»  
**Итого к записи: 27 файлов** (5 учебных звуков + 14 реплик станций + 8 коротких реакций)

Вступление уже есть в ролике — **его не читать**.  
Длинные статусы на экране («Буква А собралась!», «Вперёд к приключениям!» и т.п.) **голосом не читать** — после ответа звучит короткая реакция из блока В.  
Один звук и одна реакция пишутся **один раз** и потом переиспользуются.

## Как говорить (Буквы)

| | |
|---|---|
| С кем | ребёнок 4–7 лет, рядом взрослый |
| Тон реплик | спокойный, чуть игривый, 1–2 короткие фразы |
| Тон звуков | чисто, ровно, без театра |
| Нельзя | сюсюканье, крик, музыка на дорожке, имена букв («эм», «а как буква») |
| Звуки | только звук: «а-а-а», «м-м-м», слог «ма» |
| Пауза | 0,3–0,5 сек в конце файла |
| Дубли | 1 основной + 1 запасной |
| Формат | WAV, 48 kHz (или 44.1), моно; имя файла = колонка «файл» |

Перед блоком А: «Только звук, чисто, без слов.»  
Перед блоком Б: «Я Словик. Коротко, тепло, зову помочь.»

## А. Учебные звуки — 5 файлов

| № | файл | что произнести | куда пойдёт |
|---|---|---|---|
| 1 | `snd-a.wav` | а-а-а | нажатие на букву А; вспышка А в пещере эха |
| 2 | `snd-o.wav` | о-о-о | вспышка О в пещере эха |
| 3 | `snd-i.wav` | и-и-и | вспышка И в пещере эха |
| 4 | `snd-u.wav` | у-у-у | вспышка У в пещере эха |
| 5 | `snd-ma.wav` | ма | слог собрался (мост дружбы) |

Длина звука: примерно 1–1,5 сек. Слог «ма» — один раз, ровно, без растяжки.

## Шпаргалка произношения (Буквы)

| Пишем | Говорим | Не говорим |
|---|---|---|
| звук А | а-а-а | «буква а» |
| звук О | о-о-о | название буквы |
| звук И | и-и-и | название буквы |
| звук У | у-у-у | название буквы |
| звук М | м-м-м | эм |
| слог МА | ма | эм-а / мэ-а |

## Не записывать (Буквы)

- вступительный ролик (`bo-trial-intro`);
- шум дождя, мотора, барабана, колокольчика;
- длинные уникальные «молодец, теперь идём туда-то» — вместо них блок В;
- технические строки на экране («Вперёд к приключениям!», «Буква А собралась!» и т.п.).

**Папка сдачи:** `bo-trial/`

# Часть 2. «Первые истории»

**Урок:** «Спаси первую историю»  
**История урока (финальная книжка «Дома»):**  
ВОТ МОЙ ДОМ. ВОТ МОЙ КОТ. КОТ ЕСТ СЫР. НОЧЬ, КОТ СПИТ. МАМА СПИТ.  
**Финал на экране и в голосе:** «Ура, история прочитана!»  
**Итого к записи: 23 файла** (15 реплик станций + 8 коротких реакций; реакции можно не писать заново, если уже есть из «Букв»)

Вступление уже есть в ролике — **его не читать**.  
Ребёнок **уже читает**: не просить «послушай звук», не называть буквы «эм/эс». Говорить: «прочитай», «найди слово», «какая фраза».

## Как говорить (Истории)

| | |
|---|---|
| С кем | ребёнок 5–7 лет, рядом взрослый |
| Тон | спокойный, чуть игривый, 1–2 короткие фразы |
| Нельзя | сюсюканье, крик, музыка, «эм», «эс», «послушай звук», «тапни» |
| Пауза | 0,3–0,5 сек в конце файла |
| Дубли | 1 основной + 1 запасной |
| Формат | WAV, 48 kHz (или 44.1), моно; имя файла = колонка «файл» |

Перед записью: «Я Словик. Коротко, тепло. Ребёнок читает сам.»

| № | файл | читать в микрофон |

## Финальная история (для ориентира)

Читать ровно, по предложениям, **только если попросят отдельный дубль** книжки (в игре страницу ребёнок читает сам):

1. вот мой дом.  
2. вот мой кот.  
3. кот ест сыр.  
4. ночь, кот спит.  
5. мама спит.  

Не скороговоркой.

## Не записывать (Истории)

- вступительный ролик (`ph-trial-intro`);
- учебные звуки букв «а-а-а», «м-м-м» (они в сессии «Буквы»);
- технические подписи на экране.

**Папка сдачи:** `ph-trial/`
