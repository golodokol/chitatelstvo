# ТЗ чтецу: вступительные ролики пробных уроков

**Проект:** Читательство  
**Персонаж:** Словик (голос проводника)  
**Объём:** 2 ролика по 35–45 секунд чистой речи  
**Дата фиксации:** 16.08.2026

---

## Общие требования к записи

| Параметр | Значение |
|---|---|
| Роль | Словик — тёплый проводник, не клоун и не учитель «с указкой» |
| Слушатель | ребёнок 4–7 лет, рядом взрослый |
| Тон | спокойный, чуть игривый; улыбка в голосе |
| Темп | чуть медленнее обычной речи; паузы 0,3–0,5 сек между фразами |
| Нельзя | сюсюканье, крик, пафос, фоновая музыка на дорожке |
| Буквы | не говорить «эм», «эс» — только звуки: «м-м-м», «а-а-а», «ма» |
| Не говорить | «нажми кнопку», «на экране», «приложение» |
| Техника | тихое помещение, поп-фильтр желателен |
| Дубли | 2–3 дубля на каждый ролик |
| Формат сдачи | WAV 48 kHz / 24-bit **или** WAV 44.1 kHz; плюс mp3 320 по желанию |
| Имена файлов | `bo-trial-intro.wav`, `ph-trial-intro.wav` |

Перед каждым дублем можно проговорить себе:  
*«Я Словик. Говорю с ребёнком тепло и спокойно. Зову помочь в квесте.»*

## Ролик 1. Буквы оживают

**ID:** `bo-trial-intro`  
**Файл:** `bo-trial-intro.wav`  
**Квест:** «Словик и пропавшие звуки»  
**Хронометраж речи:** ~40 секунд

### Основной текст (читать как есть)

Привет! Я — Словик.  
Сегодня в стране звуков пропали искорки. Без них буквы не хотят дружить.  
Нам нужно найти три искорки: услышать звук, узнать букву и собрать первое маленькое сочетание.  
Я буду рядом.  
Готов? Помоги мне вернуть звуки!

### Запасной дубль B (если основной покажется тяжёлым)

Привет! Я — Словик.  
Звуки убежали — и буквы загрустили.  
Давай найдём три искорки: послушаем, найдём букву и соберём «ма».  
Я с тобой. Побежали?

## Ролик 2. Первые истории

**ID:** `ph-trial-intro`  
**Файл:** `ph-trial-intro.wav`  
**Квест:** «Спаси первую историю»  
**Хронометраж речи:** ~40 секунд

### Основной текст (читать как есть)

Привет! Я — Словик.  
Беда: моя волшебная книжка не открывается.  
Слоги убежали с тропы — и первая история не может проснуться.  
Нам нужно вернуть их домой: провести «м» к «а», собрать «ма», найти слово и разбудить историю.  
Я рядом.  
Помоги спасти первую историю?

### Запасной дубль B (короче)

Привет! Я — Словик.  
Слоги убежали — и книжка с историей закрылась.  
Давай вернём их по тропе: слог, слово, картинка.  
Помоги мне спасти первую историю?

## Контекст для чтеца (не читать в микрофон)

Эти ролики — только **вступление** к бесплатному пробному уроку.  
Дальше ребёнок проходит станции-игры; короткие реплики Словика записываются отдельно вторым заходом.

**Станции после ролика (для понимания настроения):**

Буквы оживают: Врата страны звуков → Поляна шёпотов → Пещера эха → Мастерская буквы → Охота на А → Корзина слов → Мост дружбы → Пауза в траве → Финишный сундук → Награда Словика.

Первые истории: Закрытая книжка → Камни букв → Звуковая тропа → Поляна слогов → Пауза на тропе → Домик слов → Окно истории → Ключ от книжки → Награда Словика.
