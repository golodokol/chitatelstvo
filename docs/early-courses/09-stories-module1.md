# «Первые истории» · Модуль 1 — программа

**Статус:** утверждено (22.08.2026)  
**Названия уроков:** зафиксированы 22.08.2026 — см. раздел **«Названия уроков»**  
**Аудитория:** 5–7 лет, чтение **слов целиком** (не привязка к курсу «Буквы оживают»)  
**Сквозной герой:** **кот** (из вводного) + **Словик** (нарастающая роль → финал)  
**Мета-рамка:** у Словика **полка книжек** — каждый сюжетный урок добавляет книжку; урок 4 — без новой.

---

## История vs книжка

| | **История (квест)** | **Книжка** (`book_page`) |
|---|---------------------|---------------------------|
| Формат | станции-игры | листание, 1 предложение = 1 разворот |
| Роль ребёнка | узнаёт, ищет, собирает | **читает сам** от начала до конца |
| Связь | путь к сюжету | **тот же сюжет**, «настоящая книга» |

## Принципы словаря

- Только **настоящие** русские слова; глаголы: **идёт, ждёт, спит, бежит, ловит** и т.д.
- Не использовать обрубки (**ЛОВ**, **БЕГ**, **ТЕПЛ**).
- Словарь **шире**, чем буквы А/М/У/О/С — опора на **картинку и озвучку**.
- **Без папы** в текстах и иллюстрациях (триггер для детей без отца).
- Мама — только во **вводной** книжке «Дома»; в модуле 1 **новых сюжетов про маму нет**.

## Урок 4 · «Словик проверяет память»

**Без новой истории. Без новой книжки.**

Источник: только **«Дома»**, **«Кот и коробка»**, **«Дождь за окном»**, **«Где мяч?»**.

### Блоки

| # | Игра | Навык |
|---|------|--------|
| 1 | **Какая книжка?** — картинка → 4 обложки на полке | фраза ↔ история |
| 2 | **Фраза к картинке** — 3 фразы, одна верная | понимание |
| 3 | **Порядок** — перетащить 3 фразы одной книжки | начало → конец |
| 4 | **Кто? что делает?** — КОТ / МЯЧ; **СПИТ / ЖДЁТ / БЕЖИТ** | структура |
| 5 | **Открой разворот** — листание любой из 4 книжек | повтор |
| Финал | Словик: «Ты помнишь мои книжки!» — искорка, полка не растёт | |

## Бейджи (напоминание)

- **8 бейджей** на курс; после вводного **2–3 открыты**, **5–6 закрыты** («в полном модуле»).
- Вводный: Первый шаг, Искатель искорок, Читатель (1-я книжка).
- Модуль: Словарик, Рассказчик, Следопыт смысла, …, **Друг Словика** (урок 8).
