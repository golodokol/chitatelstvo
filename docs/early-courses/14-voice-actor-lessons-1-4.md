# ТЗ чтецу: уроки 1–4 модуля (1, 3, 8, 10 сентября)

**Проект:** Читательство · персонаж **Словик**  
**Уроки:** см. `13-lessons-1-4-september.md`  
**Реакции** из пробного (`vo-ok`, `vo-yes`, `vo-good`, `vo-found`, `vo-spark`, `vo-try`, `vo-more`, `vo-chest-invite`) — **не писать заново**, если файлы уже в проде.

Итого новых учебных звуков: **8**.  
Итого новых реплик станций: **~70** (ниже по блокам; дубли B — по желанию студии).

---

## Как говорить

| | |
|---|---|
| С кем | ребёнок 4–7 лет, рядом взрослый |
| Тон | спокойный, чуть игривый, 1–2 короткие фразы |
| Нельзя | сюсюканье, крик, музыка на дорожке, «эм / эс / у как буква» |
| Звуки | только звук: м-м-м, у-у-у, о-о-о, с-с-с, а-а-а; слоги ма, мо, му, ум, ос, са, со |
| Не говорить | «нажми кнопку», «на экране», «приложение» |
| Пауза | 0,3–0,5 сек в конце файла |
| Формат | WAV 48 kHz моно; имя = колонка «файл» |

Перед звуками: «Только звук, чисто, без слов.»  
Перед репликами: «Я Словик. Коротко, тепло.»

## А. Учебные звуки — 8 файлов

| № | файл | произнести | куда |
|---|------|------------|------|
| 1 | `snd-m.wav` | м-м-м | буква М, hop, grid |
| 2 | `snd-u.wav` | у-у-у | если нет надёжного из пробного — перезаписать тем же тембром |
| 3 | `snd-o.wav` | о-о-о | то же |
| 4 | `snd-s.wav` | с-с-с | буква С; не «ш-ш-ш» |
| 5 | `snd-ma.wav` | ма | слог МА |
| 6 | `snd-mo.wav` | мо | слог МО |
| 7 | `snd-mu.wav` | му | слог МУ |
| 8 | `snd-um.wav` | ум | слог УМ |

Дополнительно по слогам уроков 3–4 (если пишем пакетом):

| файл | произнести |
|------|------------|
| `snd-os.wav` | ос |
| `snd-sa.wav` | са |
| `snd-so.wav` | со |

Слог — **один раз**, ровно, без растяжки. Гласные в звуках букв — 1–1,5 сек.

## Е. Сводка для студии

| Блок | Файлов (ориентир) |
|------|-------------------|
| Звуки букв/слогов | 8–11 |
| Общие реакции | 0–6 (если нет из пробного) |
| Буквы, уроки 1–4 | 45 реплик станций |
| Истории, уроки 1–4 | 8+14+15+8 станций + 20 страниц книжек |
| Слова-плитки | до 20 |

**Не читать** с экрана статусы вроде «Буква М собралась!» — после ответа играет короткая реакция.
