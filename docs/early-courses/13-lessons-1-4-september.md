## Новые типы станций (из фото → наши)

Референсы — детские phonics-игры. Берём **механику**, не английский контент и не «имя буквы».

| Референс | Наш `kind` | Как у нас |
|----------|------------|-----------|
| Птичка прыгает по кустам с буквами | `letter_hop` | Словик / камешек-герой прыгает по кустам на **тропе букв**. Цель — звук урока. Чужие кусты — стена. |
| Карточка `mM` + вертикальные звёзды | `meet_letter` | Карточка печатной **М / м** (кириллица). Звезда зажигается за нажатие и повтор звука. |
| Сетка 6×6 «найди все m» | `letter_grid` | Деревянная доска на поляне. Найти все нужные буквы (3–5 шт.). |
| Большая буква + бейдж «6» | `letter_count` | Собрать **6** вспышек буквы на сцене (океан/поляна). |
| Книжка: milk / mop, буква выделена | `letter_spread` | Два разворота, **только знакомые слоги/слова**. Выделена целевая буква. |
| Картинка + 4 кнопки букв | *не в модуле 1* | «Первый звук в слове» — **модуль 2**. Здесь замена: `or_choice`. |
| Комикс: буква / картинка ИЛИ другое | `or_choice` | Слева буква-герой. Справа два предмета: «чей звук?» |
| Солнце / ТВ со словом | `word_screen` | **Экран Словика** (не муравей). Одно слово целиком, озвучка. |
| Drag word → picture | `drag_match` | Жёлтые плитки слов → слоты под картинками. |
| Слоты `I am ___` | `phrase_slots` | Русские заглавные: **ВОТ МЯЧ**, **КОТ У ОКНА**. |
| Числа 1–6 на волнах | `order_step` | Камни 1–2–3: порядок фраз книжки (урок историй 4). |
| SKILLS 9/10, Replay / Next | `reward` | Доска **искорок** (3), не проценты. Кнопки «Ещё раз» / «Дальше». |

**Не переносим:** слова *use, mice, time, men, moss*; маскот-муравей; имена букв («эм»); английский sight-word на солнце.

**Правила звука:** только **м-м-м, у-у-у, о-о-о, с-с-с, а-а-а** и слоги **ма, мо, му…**

Пауза `break` — после 4–5 экранных игр, как во вводном.

# А. «Буквы оживают»

Искорки на урок: **звук · буква · слог**. Бейдж — в конце.

## 1 сентября · Урок 1 · «Мотор на поляне»

**Буква М.** Уже слышали мотор на вводном.  
**Слоги:** МА, МО, МУ. Слово-мост: **МАМА** (чтение слогами, не «первый звук в МОТОР»).

| # | id | kind | Что делает ребёнок | Искорка |
|---|-----|------|--------------------|---------|
| 1 | trail | intro_video | Тропа: загорается камень **М**. Словик: помнишь мотор? | |
| 2 | meet | meet_letter | Карточка **М м**, нажать — **м-м-м**. 1-я звезда на доске. | |
| 3 | motor | listen_pick | Картинки: **мотор** / **дождь**. Что говорит м-м-м? | звук |
| 4 | hop | letter_hop | Цель на рамке: **м**. Кусты: М, А, У, О, С. Три верных прыжка. | |
| 5 | build | build_letter | Собрать печатную **М** (две стойки + перекладина). | буква |
| 6 | grid | letter_grid | Доска 5×4: найти **все М** (4 штуки). | |
| 7 | pause | break | Встать, «погудеть как мотор» без экрана. | |
| 8 | slots | slot_build | МА (знакомо) → МО → МУ. | слог |
| 9 | spread | letter_spread | Разворот 1: мотор + **м-м-м**. Разворот 2: мама + **МА-МА**. | |
| 10 | or | or_choice | Буква М. Выбор: мотор **или** солнце. | |
| 11 | quest | mini_quest | Картинка мама → слог **МА** (не МО). | |
| 12 | chest | reward | Доска 3/3 искорки, бейдж «Знаю букву М». | |

**Не читать** слово МОТОР по буквам (там О, Т, Р). Мотор — только **картинка + звук**.

## Длина и паузы

Экранная часть: ориентир **12–18 минут** + пауза 1 минута в буквах.  
Истории без отдельного `break` (книжка — смена ритма); паузу может дать родитель после награды.

## Что сознательно не взяли из фото

- Sight words *use / time* — не наш словарь модуля.  
- *mouse → m* как «первая буква слова» — модуль 2.  
- Муравей, ноутбук, английский комикс — чужой мир; экран и ноутбук заменяет **экран Словика** и **коробка / окно / мяч**.
