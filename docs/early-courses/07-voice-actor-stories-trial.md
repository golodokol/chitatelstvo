# ТЗ чтецу: пробный урок «Первые истории»

**Проект:** Читательство  
**Персонаж:** Словик  
**Урок:** «Спаси первую историю»  
**История урока (финальная книжка «Дома»):**  
ВОТ МОЙ ДОМ. ВОТ МОЙ КОТ. КОТ ЕСТ СЫР. НОЧЬ, КОТ СПИТ. МАМА СПИТ.  
**Финал:** «Ура, история прочитана!»  
**Итого к записи: 23 файла** (15 реплик станций + 8 коротких реакций; реакции можно взять из «Букв»)

Вступление уже есть в ролике — **его не читать**.  
Ребёнок **уже читает**: не просить «послушай звук», не называть буквы «эм/эс». Говорить: «прочитай», «найди слово», «какая фраза».

---

## Как говорить

| | |
|---|---|
| С кем | ребёнок 5–7 лет, рядом взрослый |
| Тон | спокойный, чуть игривый, 1–2 короткие фразы |
| Нельзя | сюсюканье, крик, музыка, «эм», «эс», «послушай звук», «тапни» |
| Пауза | 0,3–0,5 сек в конце файла |
| Дубли | 1 основной + 1 запасной |
| Формат | WAV, 48 kHz (или 44.1), моно; имя файла = колонка «файл» |

Перед записью: «Я Словик. Коротко, тепло. Ребёнок читает сам.»

---

## А. Реплики Словика — 15 файлов

| № | файл | читать в микрофон |
|---|---|---|
| 1 | `ph-vo-meet.wav` | История начинается с дома. Прочитай слово и нажми. |
| 2 | `ph-vo-twins.wav` | Картинка уже есть. Найди слово, которое к ней подходит. |
| 3 | `ph-vo-house.wav` | Прочитай слово и найди картинку. |
| 4 | `ph-vo-match.wav` | Соедини слово и картинку из нашей истории. |
| 5 | `ph-vo-window.wav` | Прочитай фразу. Выбери картинку, которая к ней подходит. |
| 6 | `ph-vo-phrase-build.wav` | Посмотри на картинку. Выбери фразу, которая про неё. |
| 7 | `ph-vo-build.wav` | Собери фразу: сначала кот, потом ест, потом сыр. |
| 8 | `ph-vo-who.wav` | Ночь, кот спит. Кто спит? |
| 9 | `ph-vo-what.wav` | Ночь, кот спит. Найди слово НОЧЬ. |
| 10 | `ph-vo-maze.wav` | А теперь: кот ест сыр. Что ест кот? |
| 11 | `ph-vo-key.wav` | Ключ от книжки: слово, фраза, история. Читай сам. |
| 12 | `ph-vo-book.wav` | Смотри: из твоих фраз получилась целая страница! Прочитай историю до конца. |
| 13 | `ph-vo-reward.wav` | Ура, история прочитана! |
| 14 | `ph-vo-retry.wav` | История почти проснулась. Давай пройдём ещё раз. |
| 15 | `ph-vo-stones.wav` | Не торопись. Читай каждое слово до конца. |

Файл `ph-vo-stones` — запасной.  
На «Дорожках слогов» ребёнок собирает слог + слог (МАМА, ДОМИК, КОТИК) — отдельной реплики нет.

## Б. Короткие реакции — 8 файлов

Можно **не писать заново**, если уже есть `vo-ok` … из «Букв». Если писать:

| № | файл | читать в микрофон | когда |
|---|---|---|---|
| 16 | `ph-vo-ok.wav` | Правильно! | задание сделано верно |
| 17 | `ph-vo-yes.wav` | Есть! | нашёл, но задание ещё не всё |
| 18 | `ph-vo-good.wav` | Здорово! | финиш станции |
| 19 | `ph-vo-found.wav` | Нашёл! | нашёл нужное слово |
| 20 | `ph-vo-spark.wav` | Искорка с нами! | собрали искорку |
| 21 | `ph-vo-try.wav` | Попробуй ещё. | ошибка, мягко |
| 22 | `ph-vo-more.wav` | Давай ещё. | нужно повторить |
| 23 | `ph-vo-wrong.wav` | Не то. Читай ещё раз. | нажал не то слово |

## Финальная история (ориентир)

Читать ровно, по предложениям, только если попросят отдельный дубль (в игре страницу ребёнок читает сам):

1. вот мой дом.  
2. вот мой кот.  
3. кот ест сыр.  
4. ночь, кот спит.  
5. мама спит.  

Не скороговоркой.

---

## Не записывать

- вступительный ролик (`ph-trial-intro`);
- учебные звуки букв (они в сессии «Буквы»);
- технические подписи на экране.
