# Тильда: встречи early-курсов, модуль 1

## Даты (оба курса: «Буквы оживают» и «Первые истории»)

Тариф **с преподавателем**, модуль 1 — **4 встречи по четвергам**:

| Встреча | Дата | Уроки модуля |
|--------:|------|--------------|
| 1 | **3 сентября 2026** | 1–2 |
| 2 | **10 сентября 2026** | 3–4 |
| 3 | **17 сентября 2026** | 5–6 |
| 4 | **24 сентября 2026** | 7–8 |

## Что вставить на Тильде

Файл для Zero Block (HTML + CSS + JS уже собраны):

**[`docs/tilda-zero-main/00-tilda-zero-upload.html`](../tilda-zero-main/00-tilda-zero-upload.html)**

### Шаги

1. Откройте страницу курса на Tilda → Zero Block → **HTML**.
2. Замените содержимое блока целиком содержимым файла `00-tilda-zero-upload.html`.
3. Сохраните и опубликуйте страницу.
4. Проверка: запись → «Буквы оживают» или «Первые истории» → тариф «С преподавателем» → в превью модуля видны даты **3, 10, 17 и 24 сентября** и у уроков подписи встреч по четвергам.

## Что уже в коде платформы (без Тильды)

- `lessons/schedule.py` — `EARLY_MEETINGS`
- уроки `early-*-with_teacher-stage-1-lesson-01…08.json` — `meeting_number` + `live_lesson.next_meeting_label`
- модули 22 и 25 в `catalog/modules.json`

После деплоя API даты встреч подтянутся на прогресс/уроки автоматически; **лендинг на Тильде** обновляется только через файл выше.
