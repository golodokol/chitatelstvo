# «Буквы оживают» · Модуль 1 — программа

**Статус:** утверждено (22.08.2026)  
**Названия уроков:** зафиксированы 22.08.2026 — см. раздел **«Названия уроков»**  
**Аудитория:** 5–7 лет, **звук → буква → слог → слово**  
**Мир:** **Страна звуков**, проводник **Словик**  
**Мета-рамка:** **Тропа букв** — после вводного на тропе горит **А**; каждый урок зажигает новую букву; урок 8 — **все буквы вместе** на празднике.

---

## Своя методика (не копия одного букваря)

| Принцип | Как у нас |
|---------|-----------|
| Звук, не «эм-а» | только **м-м-м**, **а-а-а**, **ма** |
| Слог — единица | `slot_build`, мост слогов |
| Не алфавитный порядок | **А** (вводный) → **М, У, О, С, Р** |
| Один урок = одна буква **или** один блок слогов | урок **6** — слоги; **7** — слова |
| Урок 8 | **только повтор**, праздник, чтение слов |
| Сложное откладываем | «первый звук в слове», «буквы на вывесках» → **модуль 2** |

**После модуля 1 ребёнок знает буквы:** А, М, У, О, С, **Р** и читает короткие слова из них.

## Общая структура урока модуля

Каждый **буквенный** урок (1–5):

1. **Intro** — Словик: «На тропе зажглась новая буква»  
2. **meet_letter** — знакомство, звук  
3. **Игра на звук** — `listen_pick` / `scene_hunt` (мотив из квеста)  
4. **Игра на букву** — `build_letter` / `catch_letter` / `letter_maze`  
5. **Слоги** — `slot_build` с новой буквой + уже пройденными  
6. **mini_quest** — слог ↔ картинка  
7. **Искорка** + **сундук** (на финальных станциях)  
8. **reward** — Словик, `parent_note`

**Урок 6** — **один** урок со **всеми** слогами модуля (без новой буквы).  
**Урок 7** — слова.  
**Урок 8** — повтор и **Буквенный праздник**.

### Типы станций (из вводного)

`intro_video` · `meet_letter` · `scene_hunt` · `catch_letter` · `letter_puzzle` · `build_letter` · `sort_two` · `letter_maze` · `slot_build` · `mini_quest` · `reward`

## Искорки в модуле

Как во вводном — **3 искорки** на урок (где уместно):

| Искорка | Когда |
|---------|--------|
| **Звук** | уроки 1–5: услышал и поймал звук новой буквы |
| **Буква** | уроки 1–5: лабиринт / сборка / ловля |
| **Слог** | уроки 1–5: `slot_build`; урок **6** — три искорки **слог · слог · слог** |

Урок **7**: искорки **слог · слово · слово**.  
Урок **8**: **все три** = «праздничная тройка».
