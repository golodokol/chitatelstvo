# ТЗ чтецу: буквы модуля 1 (М, У, О, С)

**Проект:** Читательство  
**Персонаж:** Словик  
**Уроки:** М · У · О · С (самостоятельный и с педагогом — одни и те же реплики)

Пробный урок А — отдельно: `06-voice-actor-letters-trial.md` (файлы `vo-*`).

## Как говорить

| | |
|---|---|
| С кем | ребёнок 4–7 лет, рядом взрослый |
| Тон | спокойный, чуть игривый, 1–2 короткие фразы |
| Нельзя | сюсюканье, крик, музыка, названия букв («эм», «эс») |
| Звуки | только звук: «м-м-м», «у-у-у», слог «ам» / «му» |
| Пауза | 0,3–0,5 сек в конце файла |
| Дубли | 1 основной + 1 запасной |
| Формат | WAV, 48 kHz (или 44.1), моно; имя = колонка «файл» |

Перед блоком: «Я Словик. Коротко, тепло, зову помочь.»

## Важно

- У **каждой** станции свой файл — даже если текст похож на соседний урок.
- Короткие реакции (`vo-ok`, `vo-try`…) из пробного — отдельно, сюда не входят.
- Не читать длинные статусы на экране — только реплику из таблицы.
