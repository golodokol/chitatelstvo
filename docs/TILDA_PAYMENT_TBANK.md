# Оплата через Т‑Банк на странице `/zapis`

Эквайринг **Т‑Банка** (Тинькофф) на Tilda работает **только с блоком корзины ST100** — не с обычной формой BF503.

Официально: [help-ru.tilda.cc/payments/tbank](https://help-ru.tilda.cc/payments/tbank)

---

## Схема на одной странице

```
Zero Block (выбор класса, тарифа, даты)
        ↓ кнопка «Оплатить»
#order:товар =цена  →  ST100 (корзина + форма + Т‑Банк)
        ↓ после оплаты
Webhook → api.chitatelstvo.ru/webhook/register
        ↓
Страница zapis/spasibo
```

---

## 1. Т‑Банк — уже подключён (проверьте)

В **личном кабинете Т‑Банк Бизнес** → Интернет-эквайринг → ваш магазин → **Терминал**:

| Параметр | Значение |
|----------|----------|
| Подключение | **Универсальное** |
| Уведомления | **По протоколу HTTP** |
| URL уведомлений | `https://forms.tildacdn.com/payment/tinkoff/` |
| Способ оплаты | **Списывать сразу** |

В **Tilda** → Настройки сайта → **Платёжные системы** → **Т‑Банк**:

- Terminal ID и пароль (боевой терминал, после тестов)
- Режим налогообложения и онлайн-касса — по вашей бухгалтерии
- **Способ отправки данных о заполнении формы** — включите webhook (см. ниже)

---

## 2. Три товара в каталоге Tilda

Создайте **3 услуги** (не 18 — тариф определяет цену, класс уходит в hidden-поля):

| Название в каталоге (точно так) | Цена | Product ID |
|----------------------------------|------|------------|
| Читательство · Разовое | 1 490 ₽ | *(скопируйте UID)* |
| Читательство · Индивидуальное | 1 990 ₽ | *(скопируйте UID)* |
| Читательство · С преподавателем | 4 990 ₽ | *(скопируйте UID)* |

**Каталог** → создать товар → тип «Услуга» → указать цену → сохранить → скопировать **Product ID** (внизу карточки).

---

## 3. Блок ST100 на странице `/zapis`

1. **+ Блок** → **Магазин** → **ST100** «Корзина с формой заказа».
2. Расположение: **внизу страницы** (можно свернуть визуально — корзина открывается поверх).
3. **Контент ST100** → поля формы заказа:

| Подпись | Variable name | Тип | Обяз. |
|---------|---------------|-----|-------|
| Имя родителя | `parent_name` | text | да |
| Email | `parent_email` | email | да |
| Telegram | `parent_telegram` | text | нет |
| Имя ребёнка | `child_name` | text | да |
| Возраст | `child_age` | number | нет |
| Как присылать новости | `notification_channel` | select | да |
| *(скрыто)* | `module_id` | hidden | — |
| *(скрыто)* | `chosen_stage` | hidden | — |
| *(скрыто)* | `chosen_tale_number` | hidden | — |

4. **Настройки ST100** → включить **«Открывать корзину после выбора товара»**.
5. **Кнопка в корзине:** `Оплатить`.

### Webhook из корзины

**Настройки сайта** → **Формы** → **Webhook**:

```
URL:    https://api.chitatelstvo.ru/webhook/register
Method: POST
Header: X-Webhook-Secret: <ваш WEBHOOK_SECRET>
```

В **контенте ST100** → подключите этот webhook к корзине.

Важно: включите **«Отправлять только после оплаты»** (если есть в настройках webhook для заказов) — чтобы запись в API создавалась после успешного платежа Т‑Банка.

**Success URL** (в терминале Т‑Банка или ST100): страница `zapis/spasibo`.

---

## 4. Zero Block — кнопка «Оплатить»

Файл `docs/tilda_zero_zapis.html` перед оплатой:

1. Проверяет выбор класса, тарифа, даты (и сказки для разового).
2. Записывает `module_id`, `chosen_stage`, `chosen_tale_number` в hidden-поля **ST100**.
3. Открывает корзину с нужным товаром:

```
#order:Читательство · Индивидуальное =1990
#order:Читательство · С преподавателем =4990
```

Названия должны **совпадать** с каталогом (или используйте `:::uid=PRODUCT_ID` — см. [продажа одного товара](https://help-ru.tilda.cc/online-store/one-product)).

После `#order:...` Tilda откроет ST100 → родитель заполняет контакты → **Оплатить** → виджет Т‑Банка.

---

## 5. Обычная форма BF503 — не для оплаты

На `/zapis` **не нужна** отдельная форма BF503 с оплатой — Т‑Банк её не поддерживает.

Контакты и оплата — **только в ST100**.

Zero Block остаётся **над** ST100 (выбор программы).

---

## 6. Тест оплаты

1. В Tilda и Т‑Банке используйте **тестовый терминал** (только карты).
2. На `/zapis`: выберите 1 класс → Индивидуальное → 22 июня → **Оплатить**.
3. Должна открыться корзина на **1 990 ₽**, поля контактов, кнопка оплаты Т‑Банка.
4. Тестовая карта — из личного кабинета Т‑Банка.
5. Проверьте: webhook на сервере, письмо родителю, редирект на `zapis/spasibo`.

После тестов замените Terminal ID / пароль на **боевые**.
