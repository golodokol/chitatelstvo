# ТЗ и промпт: озвучка заданий урока «Царевна лягушка»

## Зачем
Ребёнок 6–8 лет должен понять задание без чтения родителем. Записываем короткие голосовые реплики к каждому шагу урока.

## Общий промпт для записи (можно читать перед каждым дублем)

Ты — тёплая ведущая литературной школы «Читательство». Говоришь с ребёнком 6–8 лет спокойно, дружелюбно, чуть медленнее обычной речи, с улыбкой в голосе. Без сюсюканья и без театрального пафоса. Чётко проговариваешь имена: Иван-царевич, Василиса Премудрая, Кощей Бессмертный, Баба-Яга. В конце фразы — мягкая пауза 0,3–0,5 сек. Не добавляй от себя слов сверх текста ниже.

Формат файла: MP3 или M4A, моно, 44,1 кГц. Имя файла — как в колонке «файл».

## Как говорить
- Темп: чуть медленнее разговорного.
- Громкость ровная, без шума и эха.
- Не читайте варианты ответов вслух в мини-тесте — только вопрос (иначе подскажете ответ).
- В задании «Кто где?» можно добавить вторую половину: «Нажми на место рядом с каждым героем» — так ребёнку понятнее с новыми кнопками.
