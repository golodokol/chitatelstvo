# Бренд Читательство — для Zero Block

## Позиционирование

- **Продукт:** литературная школа онлайн для детей 7–10 лет
- **Аудитория:** родители принимают решение, ребёнок — вторичный читатель
- **Тон:** тепло, спокойно, без давления и нотаций; уверенно, но не «корпоративно»
- **Не использовать:** мультяшные персонажи, кислотные цвета, «100% гарантия», сравнение с другими детьми

## Типографика

Предпочтительные пары (подключить в настройках сайта Tilda → Шрифты):

| Роль | Шрифт | Fallback |
|------|-------|----------|
| Заголовки | **Fraunces** или **Lora** | Georgia, serif |
| Текст | **Inter** или **Source Sans 3** | system-ui, sans-serif |

Размеры (desktop → mobile):

- H1: `clamp(2rem, 5vw, 3.25rem)` / line-height 1.15
- H2: `clamp(1.5rem, 3.5vw, 2.25rem)` / line-height 1.2
- Body: `1rem` (16px) → не меньше 15px на мобилке
- Lead: `1.125rem–1.25rem`, muted color

## Сетка и форма

- Базовая сетка: **8px**
- Радиус карточек: **16px** (крупные hero — 24px)
- Тень карточек: `0 4px 24px rgba(42, 38, 34, 0.06)`
- Секция padding: `80px 0` desktop / `48px 0` mobile
- Max-width контента: **1120px**, боковые отступы `20px`

## CTA

- Текст кнопок: «Записаться в Читательство», «Записать ребёнка», «Начать с первой сказки»
- Минимальная высота кнопки: **48px**
- Скругление кнопки: **999px** (pill) или **12px**
