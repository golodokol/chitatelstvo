# RAG-база знаний — Литературная школа онлайн

Документы в этой папке подаются в LLM через RAG для генерации наград, бейджей, сообщений и следующих шагов.

## Файлы

| Файл | Содержание |
|------|------------|
| `pravila_shkoly.md` | Правила школы, уровни, баллы, тон общения |
| `formuly_pohvaly.md` | Формулы похвалы для ребёнка и родителя |
| `arhetipy.md` | Архетипы героев и персонажей в сказках |
| `skazochnye_motivy.md` | Сказочные мотивы и темы для анализа |
| `shablony_zadaniy.md` | Шаблоны заданий на понимание, анализ и творчество |

## Как использовать

1. Индексировать все `.md` файлы в векторную базу.
2. При событии обучения (урок, задание, встреча) — искать релевантные фрагменты.
3. Передавать найденный контекст + событие в промпт LLM (см. `MVP_ЛИТЕРАТУРНАЯ_ШКОЛА_ОНЛАЙН.md`, раздел 11).

## Принципы тона

- Коротко, тепло, без давления и сравнения.
- Возраст аудитории: 7–10 лет.
- Чтение — радость, а не обязанность.
